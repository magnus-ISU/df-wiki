A template will take the form {{X}}, where "X" is the word/abbreviation used to activate that template within the brackets. A pipe ( | ) can be used after that to allow something else to be typed in its place, like this {{X|blah blah}}.

To find the page for a specific template, type "Template:X" in the "Search" bar, where X = the word/abbreviation used.

For a comprehensive list of templates, see the list of all templates, by name.
