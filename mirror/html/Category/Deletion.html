Pages in this category have been marked for deletion. For example, they could contain irrelevant or outdated data, have nonsense titles, be duplicate articles, or be unneeded redirects.

To mark a page for deletion, and have it automatically added to this category, type either {{deletion}} or {{del}} at the top of the page. If the page is a redirect, remove the redirect code. This will automatically flag an article for deletion, placing it in this category and leaving a notice on the article itself.

If possible, please provide a reason when using {{deletion}} or {{del}}, by adding a piped comment.

Example:
{{del| This is an example deletion request}}
will produce...


This page is marked for deletion. The reason given is: This is an example deletion request.
