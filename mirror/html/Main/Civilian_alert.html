DFHack-added panel for managing civilian alerts

A civilian alert was a military alert that confined all civilians (and animals) to a specific set of burrows.

The current version of vanilla Dwarf Fortress does not provide an interface for managing civilian alerts, however the underlying functionality is still present and perfectly usable. DFHack exposes a single civilian alert state via the gui/civ-alert tool (on by default in Premium version), with the burrows being configurable from a button which appears when the q Squad menu is opened.

Without using DFHack, the same effect can easily be reproduced via the Burrows menu (see Suspending Burrows).
