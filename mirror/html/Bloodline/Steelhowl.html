Steelhowl is a bloodline game done in a typical one-year fashion. A new 500-year-old world was created using DF v0.40.24 for this fortress. Using vanilla Dwarf Fortress should work, but PeridexisErrant's Lazy Newb Pack 0.40.24 r12 is highly suggested. Cobalte Armok created the world. Cobalte is the first overseer of Steelhowl.
