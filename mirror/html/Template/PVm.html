Usage

Input value -> a (default 50)
Max value -> b (default 100)
Filled square color -> y (default #ff5)
Half-filled square color -> z (default #dd0)
Other parameters include advStyle (default empty), height (default 6) and stretch (default 35).

 {{PVm|a|b|y|z}}
