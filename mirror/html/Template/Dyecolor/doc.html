This is a documentation subpage for Template:Dyecolor.
It contains usage information, categories and other content that is not part of the original template page.

Description

A very simplistic and small template that shows in-game dye colors in a small box.

Usage

{{dyecolor|HTML color name OR hex value}}
For example, {{dyecolor|green}} will output the following...
Note: If using a hex color value, the # symbol must be included.
