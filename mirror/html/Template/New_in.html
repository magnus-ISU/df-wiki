The {{New in}} message box is put at the top of articles that contain information only relevant to recently released versions of Dwarf Fortress. It notifies readers that certain features, mechanics, and elements of the game mentioned in the article are applicable to the version and after, but not versions prior to. The message box also specifies whether or not older saves from previous versions are still compatible in the version.

Usage

{{New in|1|2}}

Parameters

  • 1 – Version number.
  • 2 – Overrides the word "page" (optional).
