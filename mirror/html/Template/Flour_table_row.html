Template used for the table on the Flour page. Takes the following parameters:

  • name: Name of the crop.
  • tile: Tile character.
  • colour: Colour of the tile.
  • cprice: Price of the raw crop. Defaults to 2, by far the most common value.
  • fname: Name of the processed flour. Defaults to the name value followed by "flour".
  • fprice: Price of the processed flour. Defaults to 20, by far the most common value.
