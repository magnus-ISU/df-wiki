Template:Dwarf can be used to display dwarves close to what they appear as in Dwarf Fortress. It can be used together with the raw tile template, however it doesn't scale with the user's font size. This might lead to problems for users with uncommon settings.

Usage

{{Dwarf|1|2|3|type=}}

Parameters

  • 1 – Sets the color (#:#).
  • 2 – Sets the size. Defaults to 10px.
  • 3 – Mouseover/Tooltip.
  • type – Sets the symbol to civilian or military . Defaults to civilian icon if the parameter is not defined.
    • – Accepts civilian, civ, c, or 1.
    • – Accepts military, mil, m, or 2.
    • – Accepts adventurer, merchant, diplomat, adv,merch, dip, a, or 3.
