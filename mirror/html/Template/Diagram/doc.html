Easy to use diagram template.

Newlines are converted to new table rows. Use [#color]x to change the color of a tile. Use [#color][#bgcolor]x to change both the color and background of a tile. The optional color and bgcolor parameters can be used to change the default colors. To preserve spaces, include a spaces=yes parameter. To prevent wiki template syntax from cropping leading spaces, include \ at the start of a diagram with leading spaces.


Usage examples:
