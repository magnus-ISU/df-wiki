This is a documentation subpage for Template:Ambox.
It contains usage information, categories and other content that is not part of the original template page.

Taken from that other wiki.

Usage: 

{{ambox
|type=type (see template:ambox/type for a list of valid types)
|text=some message
|smalltext=some optional smaller message
|fix=more text (optional)
|image=none | an image ID from template:ambox/core | [[File:some image]]
}}

See the template source for less-frequently used parameters, mostly copied from Wikipedia.
