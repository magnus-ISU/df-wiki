DFFD File #

(view - edit - history - purge) Documentation

The dffd template is a useful macro for hyperlinks to the Dwarf Fortress File Depot (DFFD in shorthand). It can have two inputs: the file number, required, and a link name, optional.

{{dffd|997}} → DFFD File # 997
{{dffd|997|Dwarf Fortress Map Compressor}} → Dwarf Fortress Map Compressor
