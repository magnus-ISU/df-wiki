Takes a version number and returns the corresponding namespace.

Examples

50.03: Main

0.43.05: DF2014

0.44: DF2014 (trailing components not required)

0.34.11: v0.34

0.34.02: v0.34

0.31.19: v0.31

v0.31.07: v0.31 (Leading "v" is ignored)

0.28.121.40c: 40d

0.23.130.23a: 23a

unrecognized: cv
