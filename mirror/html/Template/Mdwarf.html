Template:mdwarf can be used to display dwarves close to what they appear as in Dwarf Fortress. It can be used together with the raw tile template, however it doesn't scale with the user's font size. This might lead to problems for users with uncommon settings.

Usage

{{mdwarf|<color>|<size>}}

Examples
