This template is to be used on all pages that are game version specific.

Usage

To use this template simply add {{av}} to the top of an article.

"There's a new version! What do I do?"

If the version is major enough to warrant a new namespace (this will have been determined by the community), then the most important thing to do is update this page with the newest namespace. This will cause all the templates to show the proper current/outdated message.

The second thing to do is update the ArticleVersion template. This template is widely used and quite complicated; please do not attempt to modify it unless you are very familiar with wiki template code. Instead, please post an update request on its talk page.

A list of templates that need to be updated in each major version can be found here.
