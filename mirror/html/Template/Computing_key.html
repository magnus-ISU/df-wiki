This template holds a list of different elements to be used to describe logic gates schematically. The elements are based on the DF characters, but are optimized for this purpose. The background colors for floors and walls for example are choosen to reduce the contrast to the white background of the wiki. Before you change something, make sure change all diagrams the elements are used in, too. I used the {{RTL}} template to create the overlaying sub- and superscript characters.
