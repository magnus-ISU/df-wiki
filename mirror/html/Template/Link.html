Experimental link template, which might reduce spam on pages linked to from high-traffic pages (especially the announcements).

Usage

This template accepts up to 10 (ordered) parameters, as well as an optional parameter for a displayed title (t=). Note that leading and trailing spaces are stripped from template arguments — that is, spaces in a parameter should have at least one non-whitespace character on each side. 

{{link|Ma|in P|ag|e}}

Main Page 

{{link|Ma|in |Pag|e}}

MainPage (trailing spaces are stripped from argument 2) 

{{link|Ma|in P|ag|e|t=Link to main page}}

Link to main page
