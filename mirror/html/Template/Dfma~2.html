Use this template to link to the Dwarf Fortress Map Archive in a simple manner. The first param is m for maps, mv for movies, the second one is the file number, and the third one is the link name.

{{dfma|m|1000}} -> DFMA Map #1000
{{dfma|mv|1000|Best Movie Ever}} -> Best Movie Ever
