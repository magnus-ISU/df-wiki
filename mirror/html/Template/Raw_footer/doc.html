This is a documentation subpage for Template:Raw footer.
It contains usage information, categories and other content that is not part of the original template page.

Description

Footer template for /raw subpages to make them more readable (and automatically categorize them).

Usage

  • <noinclude>{{raw header|symbol|DOMESTIC}}</noinclude>{{raw|v50:language_SYM.txt|SYMBOL|DOMESTIC}}<noinclude>{{raw footer|symbol|DOMESTIC}}</noinclude>

or

  • <noinclude>{{raw header|foo|BAR}}</noinclude>{{raw|v50:file.txt|FOO|BAR}}<noinclude>{{raw footer|foo|BAR}}</noinclude>
