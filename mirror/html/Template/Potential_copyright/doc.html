Add {{watch}} to the top of a page

Adding a pipe (|) after either command will change the default text to appear instead as the editor's "reasoning" for the watching.

This template will also add the respective page to the watched category. This template is only meant for content with ambiguous, unconfirmed or completely missing copyright licenses.
There is no need to type a period at the end of the reasoning, as a period is already provided in the template.

For example, {{watch|Image origin unknown}} will appear as...

This page has a potential copyright issue, and is being watched. The reason given is: Image origin unknown.
