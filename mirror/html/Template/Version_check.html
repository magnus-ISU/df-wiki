Usage

Add {{vc}} to top of page.

This template should only be used on pages that have non-standard "it doesn't work this way anymore"-type messages. If you notice something specific that's wrong (that isn't in anyway marked) this template is inappropriate for that use. Alternatively, if you're unsure whether something is about the proper version, you can add this template, and mark the specific section with {{cvsec}}.
