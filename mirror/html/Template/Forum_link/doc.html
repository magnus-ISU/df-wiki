This template is useful for quickly inserting plainlink-styled links to the Bay 12 Forums. It takes two parameters: the link number which is required, and the link name, which is optional but probably a good idea (default behavior is to use "link"). To access this template more easily (less typing) use {{Forum}} or better yet, {{F}}. You can redirect the user to specific messages within the thread, too, by linking to that header - this is provided for within the first parameter. Adding another parameter for it would probably be less ugly, but would also make more work out of filling out this template.

  • {{F|128298.msg4388413#msg4388413}} → link
  • {{F|128298/msg4388413}} → link
