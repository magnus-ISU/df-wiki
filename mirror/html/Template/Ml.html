Simple template for linking to mainspace from an article in a versioned namespace, particularly for redirects only existing in the mainspace. For example, kitten ([[kitten]]) works here, but not in a DF2012 article - you need to use kitten ([[Main:kitten|kitten]]).

Usage: Similar to using double-bracket syntax (2 parameters, link title is the first parameter if the second is left blank). 

{{ml|kitten}}

kitten 

{{ml|kitten|this page}}

this page

Note: substing this template will work, and is probably helpful in some cases (see {{unsigned}})
