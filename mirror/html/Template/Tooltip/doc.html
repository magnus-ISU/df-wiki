adds a tooltip

Usage

{{Tooltip|Has a tooltip|the tooltip alt text showing on mouse over}}

Output example

{{Tooltip|foo|bar}} produces foo

{{Tooltip|music|d "Shasad" e "Sanera" g "Bagost" h "Joñu"}}. returns music.
