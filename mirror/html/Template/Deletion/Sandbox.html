This page is marked for deletion. Reasons could include a nonsense title, superfluous information, irrelevant/lack of material or the article could be outdated/duplicated.

Usage

Add {{deletion}} or {{del}} to the top of a page

Adding a pipe ( | ) after either command will change the default text to appear instead as the editor's "reasoning" for the deletion.

For example, {{del|This is a sample deletion request}} will appear as...

This page is marked for deletion. The reason given is: This is a sample deletion request.

Adding a second pipe, {{del|This is a sample deletion request.|40}}, will allow you to set a custom width...

This page is marked for deletion. The reason given is: This is a sample deletion request..
