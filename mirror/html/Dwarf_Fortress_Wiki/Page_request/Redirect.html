Redirect requests

Redirects redirect to existing pages (usually articles). This is especially useful when searching for pages — redirects will allow users to bypass the search results list.

Please note that redirects on the Dwarf Fortress Wiki follow a different set of rules from Wikipedia. If you aren't familiar with the rules on this wiki, it may be easier to request a redirect here instead.


Please place a * before requests — this puts them in a list, keeping them organized.

Remember to sign your posts with ~~~~ (4 tildes).
