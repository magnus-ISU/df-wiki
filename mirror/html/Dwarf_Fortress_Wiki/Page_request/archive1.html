Instructions

Note that this page is intended primarily for new users (or IP's) that do not have permission to create pages. If you create an account, you will be able to create pages on your own after 3 edits.

  1. Please use the search box to check if a similar page already exists.
  2. Consider our guidelines when choosing a page name.
  3. Add a request at the top of the list, including a link to your requested page with namespace. (e.g.: [[DF2012:Fire sword]])
    1. Put an asterisk (*) before your request. (This places it in a list, which makes requests easier to pick out.)
    2. Please sign your request using ~~~~ (4 tildes).

If you need a user page or a subpage created (a sandbox, for example), post it in the User page requests section.
