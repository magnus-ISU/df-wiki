This is a guide to using redirects, of sorts. This guide is very badly written for the present time.

How to make your redirects with our new namespaces

Use [[CV:Article Name]] to redirect to the Current Version of the article.
Use [[23a:Article Name]] to redirect to the 2D game version (23a) of the article.
Use [[40d:Article Name]] to redirect to the 3D game version (40d) of the article.

For versioned articles, stick {{av}} at the top of the page and it will insert automatic links to the other article versions present.
