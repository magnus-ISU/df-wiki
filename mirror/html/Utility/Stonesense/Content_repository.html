Vegetation

Seuss's Tweaked Vegetation

Download: DFFD File
Author: Seuss
Installation: Replace vegetation folder in your stonesense directory with this one and make sure the line "vegetation/index.txt" is above "terrain/index.txt" in the main index file.
These are the vegetation files I use. I edit and change stuff as I play so this may be more updated than the official vegetation files.

An Important note: There is a small fix to the terrain under vegetation but it will only work if in your main index.txt file you have "vegetation/index.txt" above "terrain/index.txt". This is not necessary but it does improve visual quality.

Belannaer's Underground trees

Download: DFFD File (Included in: Slate 2.2)
Author: Belannaer
Installation: Extract files into Stonesense/Vegetation and add underground_trees.xml to the index.txt.
New underground trees. From left to right: black cap, nether cap, goblin cap, tunnel tube, spore tree, blood thorn, fungiwood. Fungiwood graphic is from the original trees.png in Stonesense.

Therahedwig's darker grass

http://img.ie/164bc.png
Download: DFFD File
Author: TheraHedwig
Installation: Just unzip the file inside the stonesense directory and add GD/index.txt to the index file, above all the other entries.
If you don't like the ramps, go into the GD directory, delete SSGDramps1.png and rename SSGDramps2.png into SSGDramps1.png.

Greiger's Dracon Race Pack

Download: DFFD File
Author: Greiger
Installation: Simply extract into Stonesense/Creatures and add Dracon.xml to the index file.
A set of sprites for custom dragonman races. Not useful for vanilla, but folks with a dragonman race could use these sprites to have fewer ? icons around. Updated for Stonesense slate on 5/5/2010.
