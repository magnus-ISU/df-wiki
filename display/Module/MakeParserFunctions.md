# Module:MakeParserFunctions

*[Source](https://dwarffortresswiki.org/index.php/Module:MakeParserFunctions) &middot; revision 266802 &middot; retrieved 2026-09-13 &middot; [wikitext](../../mirror/wikitext/Module/MakeParserFunctions.wiki)*

---
This module takes a table of functions that take string parameters and returns a table of functions that takes "frame" parameters and passes through their "args" to the original functions as positional arguments.

---

```
return function(env)
	local out = {}
	for k, v in pairs(env) do
		if type(v) == 'function' then
			out[k] = function(frame)
				local args = {}
				local i = 1
				while frame.args[i] do
					args[i] = frame.args[i]
					i = i + 1
				end
				return v(unpack(args))
			end
		end
	end
	return out
end
```
