This is a guide to using redirects, of sorts. This guide is very badly written for the present time.

### How to make your redirects with our new namespaces

Use \[\[CV:Article Name\]\] to redirect to the **C**urrent **V**ersion of the article.<br> Use \[\[23a:Article Name\]\] to redirect to the 2D game version (**23a**) of the article.<br> Use \[\[40d:Article Name\]\] to redirect to the 3D game version (**40d**) of the article.<br>

For versioned articles, stick {{[av](../Template/Av.md)}} at the top of the page and it will insert automatic links to the other article versions present.

| Namespace | Version | Notes |
| --- | --- | --- |
| **CV** | Namespace alias for **cv** | When a new version is released, all CV links will be updated automatically to point to the newest version. |
| **DF2010** | DF2010 |  |
| **40d** | 40d (3D version) |  |
| **23a** | 23a (2D version) |  |
