# Dwarf Fortress Wiki:Diagram

*[Source](https://dwarffortresswiki.org/index.php/Dwarf_Fortress_Wiki:Diagram) &middot; revision 198920 &middot; retrieved 2026-09-13 &middot; [wikitext](../../mirror/wikitext/Dwarf_Fortress_Wiki/Diagram.wiki)*

This wiki has a new extension: [DFDiagram](https://github.com/lethosor/DFDiagram)!

This is an expanded (and possibly more efficient) replacement for {{[diagram](../Template/Diagram.md)}}. Features include:

- An unlimited number of diagrams per page ({{[diagram](../Template/Diagram.md)}} depends on RegexFunctions, so it is limited by the Regex functions limit)
- Basic tileset support (transparency and creature graphics don't work, but all of the non-transparent tilesets in the [tileset repository](../Main/Tileset_repository~2.md) should work)
- Z-levels
- A variety of new syntax features:
  - Variables
  - Special characters
  - DF-style colors (e.g. 7:0 for light grey)

There are a couple differences between this and {{[diagram](../Template/Diagram.md)}}:

- Colors persist until explicitly changed (use \[#\] to reset the foreground color):
