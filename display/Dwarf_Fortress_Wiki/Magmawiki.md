magmawiki was a web development project to replace the mediaWiki engine. It has not been updated since 2010.

magmawiki is the project to replace the mediaWiki engine.

Source code is hosted on [Github](http://www.github.com/locriani/magmawiki).

IRC channel for **software development** (**[NOT dwarf fortress questions / discussions, check here for those channels!](../Main/IRC.md)**) is [#magmawiki on freenode.org](http://irc.freenode.org/#magmawiki)

Discussion of the magmawiki project on the forums is [here](http://www.bay12forums.com/smf/index.php?topic=55613.0)
