# Dwarf Fortress Wiki:Centralized Discussion/Feedback reporter

*[Source](https://dwarffortresswiki.org/index.php/Dwarf_Fortress_Wiki:Centralized_Discussion/Feedback_reporter) &middot; revision 191612 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../mirror/wikitext/Dwarf_Fortress_Wiki/Centralized_Discussion/Feedback_reporter.wiki)*

I've created a basic feedback reporter, which should hopefully make it easier for non-wiki people to leave feedback on articles (especially guides and essential topics). It's (mostly) functional right now, so I'm looking for ideas on how to implement it.

- This tool is currently implemented on an opt-in basis — {{[Feedback reporter](../../Template/Feedback_reporter.md)}} needs to be included in any articles where this tool can be used.
- You can currently test it by clicking [this link](#feedback), or on the [sandbox](../Sandbox.md), although it's not guaranteed to stay that way.
- Source code is available [on GitHub](https://github.com/lethosor/mw-feedback). You can also post issues there, if you like.

Comments and suggestions are much appreciated! I'll probably implement this on a couple pages in a few days, as long as there aren't any objections. You can leave feedback on [the talk page](https://dwarffortresswiki.org/index.php/Dwarf_Fortress_Wiki_talk:Centralized_Discussion/Feedback_reporter).
