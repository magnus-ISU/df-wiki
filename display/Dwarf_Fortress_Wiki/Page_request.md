## Page requests [help](https://dwarffortresswiki.org/index.php/Dwarf_Fortress_Wiki_talk:Page_request/Help)  · [discuss](https://dwarffortresswiki.org/index.php/Dwarf_Fortress_Wiki_talk:Page_request)  · [list](Page_request/List.md)

Welcome! This page allows users without the necessary permissions to request the creation of new pages.

#### A few notes:

- This is intended for *new users* (or IP's) — after 3 edits, users are able to create pages on their own. IP's wanting to create pages (particularly content pages) may want to consider [creating an account](https://dwarffortresswiki.org/index.php/Special:CreateAccount).
- Please keep in mind that a new request may not be noticed immediately. If a request goes unnoticed for a long period of time, you may want to contact another user (checking the [recent changes](https://dwarffortresswiki.org/index.php/Special:RecentChanges) should give you an idea of the most recently active users).
- **Please link to the page you would like created** (this makes it easier for editors to create pages, as well as spot created pages). Links should be formatted like this: `[[Namespace:Name]]` (or just `[[Name]]` for articles in the main namespace).

<br>
