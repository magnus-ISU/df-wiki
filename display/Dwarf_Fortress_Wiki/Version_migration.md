## Basic instructions

- Check an article to see if it is accurate
  - If it is, remove the {{[migrated article](../Template/Migrated_article.md)}} template
  - If not, update it!
    - Use [citation templates](../Category/Citation_templates.md) to help keep track of sources, if possible
    - If an article is too long to update in one edit, use {{[migrated section](../Template/Migrated_section.md)}} to mark sections needing review.
- For the v50 migration, things to keep in mind:
  - Keybinds have changed, so replace the old keybind template (i via `{{k|i}}`) with the new one ([![Ui z.png](https://dwarffortresswiki.org/images/1/13/Ui_z.png)](https://dwarffortresswiki.org/index.php/File:Ui_z.png)z [![Adv ui z.png](https://dwarffortresswiki.org/images/f/f2/Adv_ui_z.png)](https://dwarffortresswiki.org/index.php/File:Adv_ui_z.png)z via `{{Menu icon|z}}`/`{{Adv menu icon|z}}`) if possible.
  - Some skills have changed: [Building designer](../Main/Building_designer.md) is gone, and [Doctor](../Main/Doctor.md) skills/occupations work differently now. Mentions of them may need removal or verification.
  - Some features have been removed. Up-to-date articles shouldn't generally link to anything in [Category:Obsolete features](../Category/Obsolete_features.md).
  - There's generally no need to mention "as of v50" or "unlike in v0.47". That's implied by the article's version.
  - There's no need to necessarily delete images of the old interface; however, pages should have new versions of any interface images before being marked as up-to-date. When adding an image of the new interface, the {{[Dual image](../Template/Dual_image.md)}} template can be used to allow switching between old and new.
