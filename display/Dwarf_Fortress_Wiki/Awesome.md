This is awesome. Project Awesome.

### What is Project Awesome?

Occasionally Briess receives an obscene amount of free advertising through Google that never gets used. (They expire in a month, etc.) Instead of throwing this credit away, why not use it to find newbies and introduce them to Dwarf Fortress? However, to do that, we need awesome tutorials, awesome evangelism pages, and an awesome front page so newbies don't get confused.

- Project coordinators: [Briess](https://dwarffortresswiki.org/index.php/User:Briess), [Phantasm](https://dwarffortresswiki.org/index.php/User:Phantasm)

There is a possibility of prizes for Awesome contributions to project Awesome. We shall see.

#### Newbie unfriendly bugs

List of various bugs that are of importance to be fixed to make ideal playing experience for newbies. Fixing of these of course requires support from Toady One. These haven't been much of a priority as seasoned players do not get bothered about most of these bugs, but for newbies fixing of these is a must. So, the task for us it to look for bugs that should be fixed in order to allow newbie friendly introduction to DF 2010.

We don't need to wait for everything fixed right away. We could keep a list with explanations of all of these bugs and any work-arounds for Newbs to read up on --[LucasUP](https://dwarffortresswiki.org/index.php/User:LucasUP) 12:09, 3 September 2010 (UTC)

Unfortunately we need to get everything fixed, or at least as much as possible. This is because that giving a list of known bugs and work-arounds for newbies will very easily get them to stray away for good. To get the best possible benefit of the advertising, everything needs to look good. --[Phantasm](https://dwarffortresswiki.org/index.php/User:Phantasm) 15:58, 3 September 2010 (UTC)
