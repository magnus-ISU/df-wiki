# Category:Templates

*[Source](https://dwarffortresswiki.org/index.php/Category:Templates) &middot; revision 220379 &middot; retrieved 2026-09-13 &middot; [wikitext](../../mirror/wikitext/Category/Templates.wiki)*

---
A template will take the form {{X}}, where "X" is the word/abbreviation used to activate that template within the brackets. A pipe ( | ) can be used after that to allow something else to be typed in its place, like this {{X|blah blah}}.

To find the page for a specific template, type "Template:X" in the "Search" bar, where X = the word/abbreviation used.

For a comprehensive list of templates, see the [list of all templates, by name](http://dwarffortresswiki.org/index.php?title=Special:AllPages&from=&namespace=10).
