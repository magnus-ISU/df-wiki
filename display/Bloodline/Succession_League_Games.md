# Bloodline:Succession League Games

*[Source](https://dwarffortresswiki.org/index.php/Bloodline:Succession_League_Games) &middot; revision 190366 &middot; retrieved 2026-09-13 &middot; [wikitext](../../mirror/wikitext/Bloodline/Succession_League_Games.wiki)*

---
When a game is created by a Member of the [Succession League](../Main/Succession_League.md), it will go here. Players will use this to find the type of game they are looking for, and hosts will use it to find players for their games.<br>

Use the [Members](../Main/Succession_League_Members.md) section to review players who are in a game or who wish to join your game.<br>

Old games can be found in the [Archive](../Main/Succession_League_Archive.md).

## Notes

- Each game will have its own page in turn, with a short description.
  - Games ~~will be~~ are organized according to type and separated by Active, Inactive, Discontinued, and Completed.
  - Links to AAR(After Action Report)s, LP(LetsPlay on SomethingAwful forums), and other game-specific material will be listed on the game's personal page. Use of a game page's Discussion page as a forum and for posting updates and imagery is highly encouraged; if using outside forums then please post links on the Game Page. People want to see your work!<br>

- To find a game, check Inactive Games or Active Games. Discontinued and Completed are archives.

## Creating A Game

> Creating a game could be complicated due to the Wiki's code. Fortunately, you can just use this Template, as long as you don't change any punctuation. Add all you want in the designated areas. Copy it, open the editor for the section you want to add it to, paste it, then fill it in. Be sure to place it in the appropriate section. Alternately, you can ask [The Architect](https://dwarffortresswiki.org/index.php/User:The_Architect) to do it, just tell him what you want.<br>

### Template

```
{{SLG
|FortName=your fort name
|Host=~~~ (3 tildes, not 4!)
|WikiLink=Title of the Wiki Page (no Bloodline: prefix needed, optional)
|ForumLink=Full forum link address (ie http://www.bay12games.com/forum/)
|Description=Your game description.
|Type=The type of game.  Optional.
}}
```

The Wiki doesn't serve as a good forum, so discussing the choice of your fort location is better done elsewhere(people will want to discuss it with you and find the Edit-to-type and coding is a barrier. However, if you like, you can go ahead and create a game page under your GameName, and work from there to pick your site. The Wiki IS a great place to post updates, once you know how.

It will look like this:<br>
