### About the Game

Kelabras is not a classic Bloodline game as there is only one player (currently) - me. I wanted to take a journal like game (or more in the same world) and take a storylike journal about it. Since there is no other category I have chosen bloodlines for it.

### Player(s)

Currently, the only player is [vooood](https://dwarffortresswiki.org/index.php?title=User:Vooood&action=edit&redlink=1) playing the game.
