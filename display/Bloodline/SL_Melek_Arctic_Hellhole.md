### The Embark Zone

The location is an [evil](../Main/Evil.md), [glacier](../Main/Glacier.md) and [tundra](../Main/Tundra.md). There are no [trees](../Main/Trees.md) but legend has it that [magma](../Main/Magma.md) is present.

Because this is a nasty place to set up a fortress it might be worth looking up the problems regarding having too much [ice](../Main/Ice.md) on embark before you ask to join this game... boy this is going to be [fun](../Main/Fun.md).
