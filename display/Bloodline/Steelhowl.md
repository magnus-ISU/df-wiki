*Steelhowl* is a [bloodline](../Main/Bloodline.md) game done in a typical one-year fashion. A new 500-year-old world was created using DF v0.40.24 for this fortress. Using vanilla Dwarf Fortress should work, but [PeridexisErrant's Lazy Newb Pack 0.40.24 r12](http://dffd.bay12games.com/file.php?id=7622) is highly suggested. ~~[Cobalte](https://dwarffortresswiki.org/index.php/User:Cobalte)~~ Armok created the world. [Cobalte](https://dwarffortresswiki.org/index.php/User:Cobalte) is the first overseer of Steelhowl.
