**Archery targets** are used to create archery ranges, which are used to train [marksdwarves](Marksdwarves.md). They can be built from [wood](Wood.md), which requires [carpentry](Carpentry.md); [stone](Stone.md) or [glass](Glass.md), which requires [masonry](Masonry.md); or [metal](Metal.md), which requires [metalcrafting](Metalcrafting.md). They can also be built from [blocks](Block.md) made from the above materials.

### Making an archery range

To make an archery range,

1. build one or more Archery targets in a room/area
2. query over each and every constructed archery target and make a room
3. Set the size with +/- to determine how far from the target your archers will stand
4. Specify the shooting direction with wasd
5. Assign the range to the desired [squads](Squads.md). Squads can then be set to sleep or train there, as well as store their individual or squad equipment, much like a [barracks](Barracks.md).

[![](https://dwarffortresswiki.org/images/thumb/5/5b/Archery_range_room.png/150px-Archery_range_room.png)](https://dwarffortresswiki.org/index.php/File:Archery_range_room.png)

[https://dwarffortresswiki.org/index.php/File:Archery_range_room.png](https://dwarffortresswiki.org/index.php/File:Archery_range_room.png)

An archery range room.

The [room](Room.md) can then be used by military dwarves who have ***no order*** (i.e. they're set to inactive or set to only active/training)<sup>[Bug](#bugs):[6070](https://dwarffortressbugtracker.com/view.php?id=6070)</sup> in their [schedule](Schedule.md) that month, in order to train ranged [weapon](Weapon.md) [skills](Skills.md). Since [bolts](Bolts.md) are being used up by this training, it may be a good idea to [set](Equipment.md) the dwarves to only use [bone](Bone.md) or [wooden](Wood.md) bolts when training.

Unlike other [rooms](Room.md), archery ranges only include the archery target from which they were defined - if you have multiple targets in one area, **each one** must be designated as its own archery range, even if this causes them to overlap.

It is also advisable for the archery target rooms to be included in the area of the barracks where your marksdwarves train. Both the barracks and the archery targets need to be assigned to squads individually.

[![](https://dwarffortresswiki.org/images/thumb/5/52/Archery_target_preview.png/170px-Archery_target_preview.png)](https://dwarffortresswiki.org/index.php/File:Archery_target_preview.png)

[https://dwarffortresswiki.org/index.php/File:Archery_target_preview.png](https://dwarffortresswiki.org/index.php/File:Archery_target_preview.png)

Bullseye!

### Notes

- The size of the range must be large enough so that the marksdwarf is able to stand at least 1 tile away from the target (Dwarves will **not** train if the size of the range means they have to stand adjacent to the target).
- It is advisable to channel out the area behind the targets and connect a room underneath the range to save on bolts (falling bolts to not break). Note that floor grates do **not** work for this. Note that the channel has to be dug **behind** the target; if it is dug in front, the dwarves will be unable to fire, as they need a clear walking path in order to fire the bolts.
- Experience is granted per shot, not per target hit.
- Only one soldier can use an archery target at a time. This means that if you have multiple targets next to each other, you **must** designate a training grounds for each of them or only one will be used at a time.
- Marksdwarves will only practice at an archery range if their [quivers](Quiver.md) contain ammunition which is permitted for training. There was a bug that caused marksdwarves to not switch their ammo when they switch between active duty and training, but this has been fixed as of 42.03.
- Marksdwarves do not spend all of their free time performing archery practice - during downtime, they will complain that they "cannot follow orders". Assigning marksdwarves to a [barracks](Barracks.md) will allow them to use this spare time to perform combat drills, though said drills can potentially cut into archery practice.

### Bugs

- The flag for active/inactive seems to get mixed up, so marksdwarves will only use archery targets when they're inactive.<sup>[Bug](#bugs):[6070](https://dwarffortressbugtracker.com/view.php?id=6070)</sup>
