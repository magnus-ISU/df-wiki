In *Dwarf Fortress*, a **token** is a piece of text that defines the properties of an object. An "object" could be a material, a type of tissue, an organ, a piece of armor, a creature, a biome, a civilisation, or anything else in the game. A "property" could be how large something is, what it is made from, its melting temperature, its name, its biome preference (for civilisations) or anything else that makes it unique. All information associated with the properties of an object in the game is defined using tokens. Tokens are found in the [raws](Raws.md), and can be easily [modified](Modding.md), allowing users to create (and distribute) new content.

> - [Ammo tokens](Ammo_token.md) define ammunition, such as arrows and bolts.
> - [Armor tokens](Armor_token.md) define armor.
> - [Biome tokens](Biome_token.md) define environments for creatures, plants and entities (entities being civilisations).
> - [Building tokens](Building_token.md) define buildings.
> - [Body tokens](Body_token.md) determine bodily structure and materials.
> - [Body detail plan tokens](Body_detail_plan_token.md) define some details of a body, similar to body tokens.
> - [Bodygloss](Bodygloss.md) tokens perform a single-word substitution of a creature's body parts.
> - [Creature tokens](Creature_token.md) determine the properties of creatures.
> - [Creature variation tokens](Creature_variation_token.md) are used to create creatures derived from other already-existing creatures, without duplicating every single token.
> - [Descriptor color tokens](Descriptor_color_token.md) define colors used in text-based descriptions. Not to be confused with [color schemes](Color_scheme.md).
> - [Descriptor pattern tokens](Descriptor_pattern_token.md) define color patterns.
> - [Descriptor shape tokens](Descriptor_shape_token.md) define [shapes](Shape.md).
> - [Entity tokens](Entity_token.md) define entities, or [civilizations](Civilization.md).
> - [Item tokens](Item_token.md) define the most basic form of items (made specific by material tokens). Item tokens are mainly used in [reactions](Reactions.md).
> - [Item definition tokens](Item_definition_token.md) are used for actual definitions of items.
> - [Instrument tokens](Instrument_token.md) define instruments.
> - [Interaction tokens](Interaction_token.md) define interactions.
> - [Labor tokens](Labor_token.md) define labors.
> - [Language tokens](Language_token.md) define a language's vocabulary. Since fictional languages in *Dwarf Fortress* are currently only used in names, language tokens do not define grammar.
> - [Material tokens](Material_token.md) are used to refer to materials, similar to item tokens.
> - [Material definition tokens](Material_definition_token.md) are used to define materials, similar to item definition tokens.
> - [Inorganic material definition tokens](Inorganic_material_definition_token.md) are used to define inorganic materials, similar to material definition tokens.
> - [Plant tokens](Plant_token.md) define plants.
> - [Position tokens](Position_token.md) define positions in entities.
> - [Skill tokens](Skill_token.md) reference skills.
> - [Syndrome tokens](Syndrome_token.md) define syndromes.
> - [Tissue definition tokens](Tissue_definition_token.md) define tissues.
> - [Tool tokens](Tool_token.md) define tools, similar to weapon tokens.
> - [Trap component tokens](Trap_component_token.md) define traps.
> - [Unit type tokens](Unit_type_token.md) are referred to by tilesets and entities, for purposes of nobility and the like.
> - [Weapon tokens](Weapon_token.md) define weapons.
> - [World tokens](World_token.md) are used in custom world generation.

Also note [reactions](Reactions.md), which are a little more complicated than simple tokens.

This [forum](http://www.bay12games.com/forum/index.php?board=13.0) is the official DF subforum dedicated to discussions about modding.
