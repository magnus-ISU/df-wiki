Since v0.42.01, [instruments](Instruments.md) are procedurally generated for each world, but if so desired, it is still possible to define custom instruments in the raws by using an \[ITEM_INSTRUMENT\] token. Most [tool tokens](Tool_token.md) can be used as before, but there are a few instrument-specific tokens, as listed in the table below.

The information on this page is sourced from the file `raw/objects/examples and notes/item_instrument_example.txt`, which also includes useful example instrument definitions.

</td>
<td>
<ul><li>various tokens</li></ul>
</td>
<td>Defines how a musician can produce sound when using this instrument. Can be used multiple times. Valid tokens and their required additional arguments are:
<ul><li>PLUCKED_BY_BP, PLUCKED (requires two tokens, actor then target)</li>
<li>BOWED (two tokens)</li>
<li>STRUCK_BY_BP, STRUCK (two tokens)</li>
<li>VIBRATE_BP_AGAINST_OPENING</li>
<li>BLOW_AGAINST_FIPPLE, BLOW_OVER_OPENING_SIDE, BLOW_OVER_OPENING_END, BLOW_OVER_SINGLE_REED, BLOW_OVER_DOUBLE_REED, BLOW_OVER_FREE_REED</li>
<li>STRUCK_TOGETHER, SHAKEN</li>
<li>SCRAPED (two tokens), FRICTION (two tokens)</li>
<li>RESONATOR</li>
<li>BAG_OVER_REED (two tokens), AIR_OVER_REED (two tokens), AIR_OVER_FREE_REED (two tokens), AIR_AGAINST_FIPPLE (two tokens)</li></ul>
</td></tr>
<tr>
<td> <a href="#pitch-choice">PITCH_CHOICE</a>
</td>
<td>
<ul><li>method</li></ul>
</td>
<td>Defines how the pitch can be varied by the musician. Can be used multiple times. Valid methods are:
<ul><li>MEMBRANE_POSITION</li>
<li>SUBPART_CHOICE</li>
<li>KEYBOARD</li>
<li>STOPPING_FRET (requires two tokens, first for "string" second for "neck" -- or whatever is being pressed against what), STOPPING_AGAINST_BODY (two tokens), STOPPING_HOLE, STOPPING_HOLE_KEY</li>
<li>SLIDE</li>
<li>HARMONIC_SERIES</li>
<li>VALVE_ROUTES_AIR</li>
<li>BP_IN_BELL</li>
<li>FOOT_PEDALS (two token, first is what is being changed e.g. "strings", second is "body" which has pedalboard -- or whatever piece is being stepped on)</li></ul>
</td></tr>

<blockquote><p>Pitch is &lt;min&gt;:&lt;max&gt; in cents with middle C at zero.  There are 1200 cents in an octave.  The game verbally differentiates values from -4200 to 4200, but you can go outside that if you like.  The in-game generated instruments will range from roughly C0 to C8 (-4800 to 4800), sometimes beyond for really unusual ones.
</p><p>        You can also use INDEFINITE_PITCH.
</p>
</blockquote>

</td>
<td>
<ul><li>min pitch</li>
<li>max pitch</li>
<li>any number of timbre words</li></ul>
</td>

<td> <a href="#music-skill">MUSIC_SKILL</a>
</td>
<td>
<ul><li>skill token</li></ul>
</td>
<td>Which skill should be trained by playing the instrument. Any <a href="Skill_token.md">skill token</a> is valid, but the in-game generated instruments only use PLAY_KEYBOARD_INSTRUMENT, PLAY_STRINGED_INSTRUMENT, PLAY_WIND_INSTRUMENT, or PLAY_PERCUSSION_INSTRUMENT. Levels in this skill do not seem to have any effect on the quality of music produced. Can only be used once.
