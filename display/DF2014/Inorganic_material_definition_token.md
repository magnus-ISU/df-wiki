The following tokens can be used in inorganic material definitions, generally for stones, gems, and metals, but not with materials attached to plants or creatures.

| Token | Arguments | Description |
| --- | --- | --- |
| [WAFERS](#wafers) |  | Used on metals, causes the metal to be made into wafers instead of [bars](Bar.md). |
| [DEEP_SPECIAL](#deep-special) |  | Causes the stone to form hollow tubes leading to the [Underworld](Underworld.md). Used for [raw adamantine](Raw_adamantine.md). When mined, stone has a 100% yield. If no material with this token exists, hollow veins will instead be made of the first available inorganic, usually [iron](Iron.md). |
| [METAL_ORE](#metal-ore) | metal:chance | Allows the ore to be [smelted](Smelter.md) into metal in the smelter. Each token with a non-zero chance causes the game to roll d100 four times, each time creating one bar of the type requested on success. |
| [THREAD_METAL](#thread-metal) | metal:chance | Allows strands to be extracted from the metal at a [craftsdwarf's workshop](Craftsdwarf's_workshop.md). |
| [DEEP_SURFACE](#deep-surface) |  | Causes the stone to line the landscape of the [Underworld](Underworld.md). Used for [slade](Slade.md). When mined (if it's mineable), stone has a 100% yield. If no material with this token exists, other materials will be used in place of slade. Underworld spires will still be referred to as a "spire of slade" in the world's history. |
| [AQUIFER](#aquifer) |  | Allows the stone to support an [aquifer](Aquifer.md). |
| [METAMORPHIC](#metamorphic) |  | Causes the material to form [metamorphic layers](Metamorphic_layer.md). |
| [SEDIMENTARY](#sedimentary) |  | Causes the material to form [sedimentary layers](Sedimentary_layer.md). |
| [SOIL](#soil) |  | Causes the material to form [soil](Soil.md) layers, allowing it to appear in (almost) any biome. Mining is faster and produces no stones. |
| [SOIL_OCEAN](#soil-ocean) |  | Causes the material to form [pelagic sediment](Soil.md) layers beneath deep oceans. Mining is faster and produces no stones. |
| [SOIL_SAND](#soil-sand) |  | Causes the material to form [sand](Sand.md) layers, allowing it to appear in [sand deserts](Sand_desert.md) and shallow [oceans](Ocean.md). Mining is faster and produces no stones. Sand layers can also be used for making [glass](Glass.md). Can be combined with \[SOIL\]. |
| [SEDIMENTARY_OCEAN_SHALLOW](#sedimentary-ocean-shallow) |  | Permits an already \[SEDIMENTARY\] stone layer to appear underneath shallow ocean regions. |
| [SEDIMENTARY_OCEAN_DEEP](#sedimentary-ocean-deep) |  | Permits an already \[SEDIMENTARY\] stone layer to appear underneath deep ocean regions. |
| [IGNEOUS_INTRUSIVE](#igneous-intrusive) |  | Causes the material to form [igneous intrusive layers](Igneous_intrusive_layer.md). |
| [IGNEOUS_EXTRUSIVE](#igneous-extrusive) |  | Causes the material to form [igneous extrusive layers](Igneous_extrusive_layer.md). |
| [ENVIRONMENT](#environment) | class:type:freq | Specifies what types of layers will contain this mineral. Multiple instances of the same token segment will cause the rock type to occur more frequently, but won't increase its abundance in the specified environment. See below. |
| [ENVIRONMENT_SPEC](#environment-spec) | stone:type:freq | Specifies which specific minerals will contain this mineral. See below. |
| [LAVA](#lava) |  | Specifies that the stone is created when combining [water](Water.md) and [magma](Magma.md), also causing it to line the edges of [magma](Magma.md) pools and volcanoes. If multiple minerals are marked as lava stones, a different one will be used in each biome or geological region. |
| [SPECIAL](#special) |  | Prevents the material from showing up in certain places. AI-controlled entities won't use the material to make items and don't bring it in caravans, though the player can use it as normal. Also, inorganic generated creatures (forgotten beasts, titans, demons) will never be composed of this material. Explicitly set by all [evil weather](Evil_weather.md) materials and implied by \[DEEP_SURFACE\] and \[DEEP_SPECIAL\]. |
| [GENERATED](#generated) |  | Indicates that this is a generated material. Cannot be specified in user-defined raws. |
| [DIVINE](#divine) |  | Found on random-generated metals and cloth. Marks this material as usable by [Deity](Deity.md)-created generated entities. |
| [SPHERE](#sphere) | [sphere](Sphere.md) | Found on divine materials. Presumably links the material to a god of the same sphere. |

### ENVIRONMENT and ENVIRONMENT_SPEC

Format:

- \[ENVIRONMENT:\<class\>:\<inclusion type\>:\<frequency\>\]

Possible values for class:

| Environment class token | Description |
| --- | --- |
| [ALL_STONE](#all-stone) | Will appear in every stone. |
| [IGNEOUS_ALL](#igneous-all),  [IGNEOUS_INTRUSIVE](#igneous-intrusive),  [IGNEOUS_EXTRUSIVE](#igneous-extrusive) | Will appear in igneous layers, either [igneous intrusive](Igneous_intrusive.md), [igneous extrusive](Igneous_extrusive.md), or both. |
| [SOIL](#soil),  [SOIL_OCEAN](#soil-ocean),  [SOIL_SAND](#soil-sand) | Will appear in soil. SOIL_OCEAN is oceans specifically and SOIL_SAND is sand specifically. |
| [METAMORPHIC](#metamorphic) | Will appear in [metamorphic](Metamorphic.md) layers. |
| [SEDIMENTARY](#sedimentary) | Will appear in [sedimentary](Sedimentary.md) layers. |
| [ALLUVIAL](#alluvial) | Will appear in [alluvial](Alluvial.md) layers. |

Possible values for inclusion type:

| Inclusion type token | Description |
| --- | --- |
| [CLUSTER](#cluster) | Large ovoids that occupy their entire 48x48 embark tile. [Microcline](Microcline.md) is an example. When mined, stone has a 25% yield (as with layer stones). |
| [CLUSTER_SMALL](#cluster-small) | Blobs of 3-9 tiles. Will always be successfully mined. [Red pyropes](Red_pyrope.md) are an example. When mined, stone has a 100% yield. |
| [CLUSTER_ONE](#cluster-one) | Single tiles. Will always be successfully mined. [Clear diamonds](Clear_diamond.md) are an example. When mined, stone has a 100% yield. |
| [VEIN](#vein) | Large streaks of stone. [Native gold](Native_gold.md) is an example. When mined, stone has a 33% yield instead of the usual 25%. |

An inclusion may be contained within a larger inclusion. For example, diamond small clusters are found within kimberlite veins.

The frequency number varies from 1 to 100 and determines the relative frequency at which the stone will be chosen to appear - if all frequency values are the same, then all stones will be equally likely to appear.

<br> ENVIRONMENT_SPEC follows much the same format, but takes a specific stone material ID where ENVIRONMENT would take a class token. What you can use will depend on what inorganic raws are around.
