Tokens used to define descriptor patterns, that may be used instead of [descriptor colors](Color.md#color-tokens). As an example, the descriptor pattern STRIPES_ORANGE_BLACK is what gives tigers their stripes.

### Tokens

<table>
<tbody><tr>
<th>Token
</th>
<th>Arguments
</th>
<th>Usage
</th>
<th>Description
</th></tr>
<tr>
<td> <a href="#pattern">PATTERN</a>
</td>
<td>SPOTS, STRIPES, MOTTLED, IRIS_EYE or PUPIL_EYE
</td>
<td>Required
</td>
<td>The type of pattern, deciding the description.
<ul><li>SPOTS: Causes a crash if no CP_COLOR is given<sup><a href="#bugs">Bug</a>:<a href="https://dwarffortressbugtracker.com/view.php?id=11806">11806</a></sup>, otherwise takes any amount.</li>
<li>STRIPES: Takes any amount of CP_COLOR tokens.</li>
<li>MOTTLED: Takes any amount of CP_COLOR tokens.</li>
<li>IRIS_EYE: Only shows the third CP_COLOR given; technically takes any amount. Causes a crash if no CP_COLOR is given<sup><a href="#bugs">Bug</a>:<a href="https://dwarffortressbugtracker.com/view.php?id=11806">11806</a></sup>. If only one or two CP_COLORs is given, the tissue is described as being "transparent".</li>
<li>PUPIL_EYE: Only shows the second CP_COLOR given; technically takes any amount. Causes a crash if no CP_COLOR is given<sup><a href="#bugs">Bug</a>:<a href="https://dwarffortressbugtracker.com/view.php?id=11806">11806</a></sup>. If only one CP_COLORs is given, the tissue is described as being "transparent".</li></ul>
<p>An undefined pattern type causes the description to simply not show up. 
</p>
</td></tr>
<tr>
<td> <a href="#cp-color">CP_COLOR</a>
</td>
<td><a href="Color.md#color-tokens">color token</a>
</td>
<td>Required (mostly)
</td>
<td>A color to be used in the pattern. See <a href="Descriptor_pattern_token.md#pattern">PATTERN</a> for how many CP_COLOR tokens are needed, and how they are used. <a href="Descriptor_color_token.md">Modded color tokens</a> may be used.
</td></tr></tbody></table>
