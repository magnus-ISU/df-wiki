**Speech files** are text files that define sentences which can be spoken by people in [adventure mode](Adventure_mode.md). They are found in the `data/speech` folder.

### Special tokens

Speech files can contain tokens in square brackets (`[]`), which are replaced with context-specific strings before the speech is displayed.
