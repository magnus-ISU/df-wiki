**Trifle pewter** is an [alloy](Alloy.md) of [tin](Tin.md) and [copper](Copper.md).

Trifle pewter can be made using one of the following recipes:

- 2 [Tin](Tin.md) bars + 1 [Copper](Copper.md) bar = 3 Trifle pewter bars
- 2 [Cassiterite](Cassiterite.md) + 1 [Native copper](Native_copper.md), [Malachite](Malachite.md), or [Tetrahedrite](Tetrahedrite.md) = 12 Trifle pewter bars

Trifle pewter has a base value of 4, making it better for objects of wealth than its ingredients, whose base values are merely 2. Using tin and copper in this way is, however, still not advisable because [fine pewter](Fine_pewter.md) and [bronze](Bronze.md) use the same ingredients (with different formulae), but have base values of 5.
