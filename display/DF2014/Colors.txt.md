The **colors.txt** file defines the [color scheme](Color_scheme.md) used by DF, in standard RGB color code.

### Default colors.txt

|  |  |
| --- | --- |
| BLACK | DGRAY |
| BLUE | LBLUE |
| GREEN | LGREEN |
| CYAN | LCYAN |
| RED | LRED |
| MAGENTA | LMAGENTA |
| BROWN | YELLOW |
| LGRAY | WHITE |
