A collection of third-party **Utilities** that are useful for *[Dwarf Fortress](Dwarf_Fortress.md)* players and [modders](Modding.md) alike, of which this page serves as a list. *Dwarf Fortress* is a difficult game to play, and any help that can be had in the task is welcome help.

If you would like to add an article on a *specific* game utility to the wiki, please do so under the [Utility](http://dwarffortresswiki.org/index.php?title=Special%3AAllPages&from=&to=&namespace=102) namespace. Not included on this page: [tileset repositories](../Main/Tileset_repository~2.md) and [graphics set repositories](../Main/Graphics_set_repository.md), due to having been given their own, separate pages. [Mods](Modding.md) have also been listed under their own [Modification](http://dwarffortresswiki.org/index.php?title=Special%3AAllPages&from=&to=&namespace=104) namespace.

To avoid namespace clutter, websites *are* considered utilities and have been included.

A [subsection of the Bay12 forums](http://www.bay12forums.com/smf/index.php?board=29.0) is devoted to such third-party programs, and contains development threads for most of them.

The [Lazy Newb Pack](Utilities.md#lazy-newb-pack) is an effort to make *Dwarf Fortress* more accessible for new players or returning veterans by bundling and configuring utilities, graphics and tilesets, and extras such as reference material or more intuitive controls.

### Launchers

#### Starter Pack

> *Main article: [Starter Pack](../Main/Starter_pack.md)*

[![](https://dwarffortresswiki.org/images/thumb/e/ed/Lnp-gui1.png/91px-Lnp-gui1.png)](https://dwarffortresswiki.org/index.php/File:Lnp-gui1.png)

[https://dwarffortresswiki.org/index.php/File:Lnp-gui1.png](https://dwarffortresswiki.org/index.php/File:Lnp-gui1.png)

The original LNP launcher

A starter pack is a compilation of tools, [tilesets](Graphics_set_repository.md), a launcher, and the game itself. It allows you to start playing DF really quickly on a new machine - no need to download all the latest stuff, check dependencies, and integrate - or even know what you need to get. Packs that include [DFHack](DFHack.md) also include third-party fixes for some bugs, enabled automatically, and significant user interface improvements. The launcher makes changing settings or graphics options much easier (press button, instead of editing files) and can even remember to launch selected utilities whenever you open a game of *Dwarf Fortress*. See [Where do I get a Pack?](../Utility/Lazy_Newb_Pack.md#where-do-i-get-a-pack) for a list.

#### PyLNP

A cross-platform LNP port, written in Python. The current launcher and configuration interface in starter packs. See [PyLNP: The modern cross platform launcher](../Utility/Lazy_Newb_Pack.md#pylnp-the-modern-cross-platform-launcher) for more information.

- Links: [Bay12 Forum Thread](http://www.bay12forums.com/smf/index.php?topic=140808), [Releases](https://github.com/Pidgeot/python-lnp/releases) (for pack maintainers), [GitHub Repository](https://github.com/Pidgeot/python-lnp), [Documentation](http://pylnp.birdiesoft.dk/docs/dev/content.html)

#### Manila Launcher (obsolete)

A Java interface that allows easy option toggling, update and devlog checking, and tileset, mod and color scheme switching. Designed for players who prefer vanilla DF to a bundle like the above. Has not been updated since 2014.

- Links: [Bay12 Forum Thread](http://www.bay12forums.com/smf/index.php?topic=102316)

### 3D Visualizers

#### Stonesense

[![Stonesense prev.jpg](https://dwarffortresswiki.org/images/thumb/d/d5/Stonesense_prev.jpg/200px-Stonesense_prev.jpg)](https://dwarffortresswiki.org/index.php/File:Stonesense_prev.jpg)

Stonesense is a third party visualizer, implemented as a [DFHack](../Utility/DFHack.md) plugin, that lets you view your fortress in a classic isometric perspective. It runs alongside *Dwarf Fortress*, and can follow the main game's view, updating in real-time. It is included in DFHack, and can be opened by typing `stonesense` or `ssense` into the console window.

- Links: [Utility:Stonesense](../Utility/Stonesense.md)

#### Armok Vision

[![Armok vision.png](https://dwarffortresswiki.org/images/thumb/f/ff/Armok_vision.png/200px-Armok_vision.png)](https://dwarffortresswiki.org/index.php/File:Armok_vision.png)

Armok Vision is a 3D real-time visualizer using Unity. It works as a separate program communicating with the game through fast network interfaces provided by DFHack.

- Links: [Bay12 Forum Thread](http://www.bay12forums.com/smf/index.php?topic=146473), [GitHub Repository](https://github.com/RosaryMala/armok-vision), [Discord](https://discord.gg/rMpYGHy), [Patreon](https://www.patreon.com/japamala)

#### Isoworld

[![Isoworld prev.png](https://dwarffortresswiki.org/images/thumb/8/84/Isoworld_prev.png/200px-Isoworld_prev.png)](https://dwarffortresswiki.org/index.php/File:Isoworld_prev.png)

Isoworld is an isometric world map viewer, which can display each of the detailed maps exported from [Legends mode](Legends_mode.md). It also has a pictographic view which makes finding waterfalls easy.

Isoworld can link with [DFHack](../Utility/DFHack.md) to display a game view at full spatial resolution in wider context, including tracking the player's view. This is particularly useful for adventure mode. The isoworldremote plugin required for this is included with DFHack.

- Links: [Bay12 Forum Thread](http://www.bay12forums.com/smf/index.php?topic=70700), [GitHub Repository](https://github.com/RosaryMala/isoworld)

#### Voxel Fortress

[![Voxel prev.png](https://dwarffortresswiki.org/images/thumb/7/77/Voxel_prev.png/200px-Voxel_prev.png)](https://dwarffortresswiki.org/index.php/File:Voxel_prev.png)

Voxel Fortress converts DF worlds to a voxel format. It takes an export of one of the two elevation maps (for the voxels coordinates), and any other one (for the colors).

The map is saved in .xraw format. An additional utility (e.g. [MagicaVoxel Viewer](https://ephtracy.github.io/index.html?page=mv_renderer)) is required to see the voxel representation of the map.

- Links: [Bay12 Forum Thread](http://www.bay12forums.com/smf/index.php?topic=159578), [GitHub Repository](https://github.com/RosaryMala/VoxelFortress/releases/tag/v1.0.0) (includes some instructions)

### Music and Sounds

#### SoundSense

> *Main article: [Utility:SoundSense](../Utility/SoundSense.md)*

[![Soundsense prev.png](https://dwarffortresswiki.org/images/thumb/0/08/Soundsense_prev.png/100px-Soundsense_prev.png)](https://dwarffortresswiki.org/index.php/File:Soundsense_prev.png)

SoundSense parses game logs and plays reacts to game events with sound effects, incidental music and dwarfy comments. Due to it being written in Java, Soundsense is portable to all platforms.

Note that older Soundsense users may have different default seasonal soundtracks, which were removed and replaced in early 2011. These are available [here](http://www.krauselabs.net/dump/music.zip).

- Links: [Website](http://df.zweistein.cz/soundsense/), [Bay12 Forum Thread](http://www.bay12forums.com/smf/index.php?topic=60287), [Google Code Repository](https://code.google.com/archive/p/df-soundsense/)

#### SoundCenSe

[![SoundCenSe prev.png](https://dwarffortresswiki.org/images/thumb/3/3f/SoundCenSe_prev.png/100px-SoundCenSe_prev.png)](https://dwarffortresswiki.org/index.php/File:SoundCenSe_prev.png)

A C# port of SoundSense, it uses the existing sound pack files and XMLs present in SoundSense, but with some added enhancements. More information regarding what specific type of enhancements and how to install SoundCenSe can be gathered at the [official forum thread](http://www.bay12forums.com/smf/index.php?topic=159567.0). If problems emerge while trying to get SoundSense to work with the latest versions of Java, this port may prove to be a useful alternative.

- Links: [Bay12 Forum Thread](http://www.bay12forums.com/smf/index.php?topic=159567), [Releases](https://github.com/Algorithman/SoundCenSe/releases), [GitHub Repository](https://github.com/Algorithman/SoundCenSe)

#### SoundSense-RS

[![SoundSense-RS prev.png](https://dwarffortresswiki.org/images/thumb/8/89/SoundSense-RS_prev.png/100px-SoundSense-RS_prev.png)](https://dwarffortresswiki.org/index.php/File:SoundSense-RS_prev.png)

A SoundSense alternative in Rust with a minimalistic GUI. Sound volumes can be adjusted realtime, based on channel. Events can be ignored with a custom list based on log patterns.

- Links: [Bay12 Forum Thread](http://www.bay12forums.com/smf/index.php?topic=174585), [Releases](https://github.com/prixt/soundsense-rs/releases), [GitHub Repository](https://github.com/prixt/soundsense-rs)

### Game manipulation tools

#### DFHack

> *Main article: [Utility:DFHack](../Utility/DFHack.md)*

[![Dfhack cmd.png](https://dwarffortresswiki.org/images/thumb/4/48/Dfhack_cmd.png/200px-Dfhack_cmd.png)](https://dwarffortresswiki.org/index.php/File:Dfhack_cmd.png)

DFHack is an advanced *Dwarf Fortress* memory access library and a set of tools and scripts using this library, providing direct object-oriented access to Dwarf Fortress's internals as if it were compiled into the game itself. Runs on Windows, Linux, and OS X. The standard configuration enables a variety of included bugfixes and interface upgrades, and provides many useful tools such as "clean all". See [main page](../Utility/DFHack.md) for a summary of features, common use, and more.

- Links: [Bay12 Forum Thread](http://www.bay12forums.com/smf/index.php?topic=164123), [Documentation](https://docs.dfhack.org/en/0.47.05-r8/), [Releases](https://github.com/DFHack/dfhack/releases), [GitHub Repository](https://github.com/DFHack/dfhack)

#### Dwarf Therapist

> *Main article: [Utility:Dwarf therapist](../Utility/Dwarf_therapist.md)*

[![Dwarf therapist.png](https://dwarffortresswiki.org/images/thumb/1/10/Dwarf_therapist.png/200px-Dwarf_therapist.png)](https://dwarffortresswiki.org/index.php/File:Dwarf_therapist.png)

Dwarf Therapist gives you an advanced GUI to manage and check dwarf job allocations, military assignments, statistics (such as attributes, personality traits and happiness), sort dwarves by various criteria (e.g. profession, migration wave, happiness, number of assigned jobs etc.) and generally manage the Dwarven Resources of your fortress in a very convenient way. Available for Windows, Mac and GNU + Linux and included in most starter packs.

- Links: [Bay12 Forum Thread](http://www.bay12forums.com/smf/index.php?topic=168411), [Releases](https://github.com/Dwarf-Therapist/Dwarf-Therapist/releases), [GitHub Repository](https://github.com/Dwarf-Therapist/Dwarf-Therapist/), [Manual](https://github.com/Dwarf-Therapist/Manual/releases) (outdated)

### Modding tools

#### [Rubble](http://www.bay12forums.com/smf/index.php?topic=140853.0)

A useful plugin-based modding tool that generates raws and supports easy installation of reactions, tilesets, macros, modding fixes and DFHack scripts. It is a fork of the now abandoned [Blast](http://www.bay12forums.com/smf/index.php?topic=125997.0). Binaries are available for Linux 32-bits, OS X 32-bits and Windows 64-bits, as well as the source (written in Go with building instructions). As of 4.0, a GUI is available for Windows.

#### [PyDwarf](http://www.bay12forums.com/smf/index.php?topic=150857.0)

For players, PyDwarf is an easy way to manage and configure preferred mods in a way that avoids almost entirely the problems of outdated mods or incompatible groups of mods. For modders, PyDwarf's mod manager exposes a powerful Python API for interacting with raws and other data files.

#### [Raw Explorer](http://www.bay12forums.com/smf/index.php?topic=103360)

A tree-based raw files browser, editor and manager.

#### [Dwarf_RAW](http://www.bay12forums.com/smf/index.php?topic=174431.0)

A GUI for editing raw files, updated 2019.

#### [Dwarf Fortress real-life material helper](http://www.bay12forums.com/smf/index.php?topic=140645.0)

A Python script that generates raws based on custom real-life material values.

#### [Roses' Random Creature Script](http://www.bay12forums.com/smf/index.php?topic=140688.0)

A Python script that generates random creature raws.

#### [DF Diagnosipack](http://www.bay12forums.com/smf/index.php?topic=175695.0)

A collection of modding tools, with a focus on diagnosing problems and getting statistics on what is found within the raws. It includes:

- DF Duplisearch - checks your raws folder for duplicated objects, and counts the number of objects of each type (creature, entity, reaction, etc.).
- DF Creatureclasser - tells you what [creature classes](../Main/Creature_token~2.md#creature-class) are in your raws, and what they are used for.
- DF CVunpack - unpacks creature variations, so you can see how the raws for e.g. wolf men really look (spoiler: they have 7 fingers).
- DF Creaturescale - calculates creature weights, and the proportions of each body part and tissue.
- DF Biomeviewer - shows what creature/plants can be found in which biomes.
- DF Rawminer - extracts procedurally generated raws (of Forgotten Beasts etc.) from save files.

#### [DF RAW Language server](https://gitlab.com/df-modding-tools/df-raw-language-server)

Modding support for DF RAW files in IDE/Code/Text editors. Checks syntax of files, detects errors and syntax highlighting.

Current extensions:

### Remote playing tools

#### [Dfterm3](../Utility/Dfterm3.md)

[Dfterm3](../Utility/Dfterm3.md) is a remote *Dwarf Fortress*-playing software for multiple users through a web interface. DFterm3 enables play through a web interface, and games can also be viewed on mobile - or even played if a bluetooth keyboard is attached. The web interface should work with Chrome or Firefox browsers, but there are known problems using Internet Explorer. DFTerm3 functions via a DFHack plugin, and is thus dependent on each version of DFHack.

It is a successor to [dfterm2](../Utility/Dfterm2.md), which functions similarly using telnet instead of a web browser. This utility only works with version 0.34.11 or earlier.

#### [Webfort](http://www.bay12forums.com/smf/index.php?topic=139167.0)

[![](https://dwarffortresswiki.org/images/thumb/6/65/Webfortress.png/200px-Webfortress.png)](https://dwarffortresswiki.org/index.php/File:Webfortress.png)

[https://dwarffortresswiki.org/index.php/File:Webfortress.png](https://dwarffortresswiki.org/index.php/File:Webfortress.png)

Playable in Mac browser.

A newer alternative to dfterm3 that functions similarly, but players must wait in a queue before assuming control for a given period of time. It also functions via a DFHack plugin. Binaries are available for Windows, as well as the source (written in C++). *(Note: [main repo](https://github.com/mifki/df-webfort) unmaintained. [New repo](https://github.com/Ankoku/df-webfort) last updated 5/22/2015.)*

#### [DorfServer](http://www.bay12forums.com/smf/index.php?topic=140892.0)

[![](https://dwarffortresswiki.org/images/thumb/1/1c/Dorfserver.png/200px-Dorfserver.png)](https://dwarffortresswiki.org/index.php/File:Dorfserver.png)

[https://dwarffortresswiki.org/index.php/File:Dorfserver.png](https://dwarffortresswiki.org/index.php/File:Dorfserver.png)

Like Twitch, without Twitch.

A remote SSH-based *Dwarf Fortress* host software. ([repo](http://www.bay12forums.com/smf/index.php?topic=140892.0))

#### [DFEverywhere](http://www.bay12forums.com/smf/index.php?topic=139975.0)

A utility that connects a locally-run *Dwarf Fortress* instance to a proprietary remote website, allowing remote browser-based play. *(Note: Main website no longer available. [Client source here.](https://github.com/tpainter/df_everywhere))*

#### [Dwarf Fortress Remote](http://mifki.com/df)

iOS app (paid) that allows one to play *Dwarf Fortress* remotely with native UI. A server can be set up at home, or on DigitalOcean, AWS or other hosting service.

#### [DFPlex](http://www.bay12forums.com/smf/index.php?topic=176070.msg)

DFPlex is a plugin for DFHack which introduces simultaneous, real-time online co-op to fortress mode: each player has their own independent view, cursor, menus, etc. so nobody has to wrestle for control. It's a fork of webfort, so players join just by connecting from their web browser.

#### [Box64](https://github.com/ptitSeb/box64)

Box64 allows Dwarf Fortress to be run locally on Android devices. A more detailed tutorial is available [here](https://www.reddit.com/r/dwarffortress/comments/r80m7y/dwarf_fortress_mobile_running_dwarf_fortress_on/).

### Announcement tools

#### [DF Assistant](http://www.bay12forums.com/smf/index.php?topic=177653)

Game events are split between advisors, each responsible for a separate aspect of your fortress: - Chief Advisor: keeps track of only the most important events that you don't want to miss - Military Advisor: combat injuries, deaths, big fights, etc - Engineering Advisor: building, maintenance, material shortages, etc - Creature Advisor: anything that lives in and around your fortress, what they think, how they feel, etc. - Miscellaneous Advisor: rest of the events, like weather, trading, thievery, etc.

Also has configurable sound effects and a bunch of thematic music!

#### [DFMon](http://www.bay12forums.com/smf/index.php?topic=130590)

An announcement monitoring/filtering program, useful to hide some types of job cancellation spam or other more advanced filtering. Note that you can set the game to announce no job cancellations *without* any utilities or mods from the orders menu, with x.

#### [DF Announcement Filter](http://www.bay12forums.com/smf/index.php?topic=130030)

An alternative to DFMon written in Java (and thus portable to Linux and OS X).

#### [Announcement Window+](http://www.bay12forums.com/smf/index.php?topic=153777)

Announcement Window+ is a Python application that interfaces with *Dwarf Fortress* to print announcements and combat reports to a separate window. It was written to fix some annoying bugs that are present in DF Announcement Filter, which is no longer being updated.

### Filesharing websites

#### [Dwarf Fortress File Depot](http://dffd.wimbli.com/)

The Dwarf Fortress File Upload Service - an excellent place to store mods, community games, tilesets and other files. Courtesy of [Janus](https://dwarffortresswiki.org/index.php/User:Janus); for files related to *Dwarf Fortress* only.

#### [Dwarf Fortress Map Archive](http://mkv25.net/dfma/)

> *Main article: [Utility:Dwarf Fortress Map Archive](../Utility/Dwarf_Fortress_Map_Archive.md)*

The Dwarf Fortress Map Archive is a large collection of user-submitted maps and videos and a nice flash viewer for perusing them. Maps are uploaded, stored, and downloaded in a special compressed format created by the DF Map Compressor; videos are stored in a compressed version of Toady One's own video-recording format.

Read more about the [DF Map Archive](https://dwarffortresswiki.org/index.php/User:Markavian/DF_Map_Archive) on Markavian's User page.

### Other/miscellaneous

#### [DF Map Compressor](http://shadowlord13.googlepages.com/dfmap-index.html)

[![](https://dwarffortresswiki.org/images/thumb/c/c6/Dfmapcomp.png/200px-Dfmapcomp.png)](https://dwarffortresswiki.org/index.php/File:Dfmapcomp.png)

[https://dwarffortresswiki.org/index.php/File:Dfmapcomp.png](https://dwarffortresswiki.org/index.php/File:Dfmapcomp.png)

Main program window.

The DF Map Compressor encodes multiple bitmaps exported from *Dwarf Fortress* into a single, very compressed, .fdf-map file. The fdf-map file can then be shared with your friends by uploading to the DF Map Archive.

#### [Exita](http://www.mindwerks.net/projects/exita/)

Exita is a Python program that takes your DF world map exports and dump them into several different text outputs.

#### [DwarfFamily](http://www.bay12forums.com/smf/index.php?topic=132153.0)

A tool that lets you import your legends XML file and converts all dwarf entries to a .GED file, which you can use in Family Tree programs like MyHeritage to display a family tree for the dwarves.

#### [Dwarf Fortress News - Android App](https://play.google.com/store/apps/details?id=dae.dfnews)

Watches the *Dwarf Fortress* devblog. Receives Push Notifications on new updates.

#### [DF2HTML](https://github.com/eniteris/df2html)

Converts DF screenshots into formatted HTML.
