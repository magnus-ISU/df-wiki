The [tokens](Token.md) for all types of [armor](Armor.md) on all slots, including [shields](Shield.md). Usage column gives information on what types of **armor** the token might be restricted to.

These tokens can only be placed within an ITEM_ARMOR, ITEM_GLOVES, ITEM_SHOES, ITEM_SHIELD, ITEM_HELM, or ITEM_PANTS object definition, most do not function in weapon objects.
