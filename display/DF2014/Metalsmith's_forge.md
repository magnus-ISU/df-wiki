> *Not to be confused with [Magma forge](Magma_forge.md).*

[![](https://dwarffortresswiki.org/images/thumb/6/69/Blacksmith_dwarf.jpg/222px-Blacksmith_dwarf.jpg)](https://dwarffortresswiki.org/index.php/File:Blacksmith_dwarf.jpg)

[https://dwarffortresswiki.org/index.php/File:Blacksmith_dwarf.jpg](https://dwarffortresswiki.org/index.php/File:Blacksmith_dwarf.jpg)

The lack of height helps him focus.

The **metalsmith's forge** is a [workshop](Workshop.md) used by [dwarves](Dwarf.md) to turn [metal bars](Metal.md) into useful objects such as [weapons](Weapon.md), [armor](Armor.md), [furniture](Furniture.md), [coins](Currency.md), [ammunition](Ammunition.md) for [siege](Siege.md) equipment and [crossbows](Crossbow.md), [trap components](Trap_component.md), and other [finished goods](Finished_goods.md). Depending on the generated world, musical [instrument](Instrument.md) components may or may not be built here. To build a forge, you must have [fire-safe](Fire-safe.md) materials and an [anvil](Anvil.md). Every use of the forge, except for [studding](Decoration.md), consumes one unit of [fuel](Fuel.md) ([coke](Coke.md) or [charcoal](Charcoal.md)).

Note that the anvil used to build a metalsmith's forge *does* need to be fire-safe—normally anvils can only be made from fire-safe materials, but [strange moods](Strange_mood.md) can create artifact anvils out of metals like [tin](Tin.md), which are entirely unusable.

### Workshop labors and skills

All metallic end products are created at a metalsmith's forge, using four of the five [metalsmithing](Metal_industry.md) skills (the exception being [smelting](Smelting.md)):

- [Weaponsmiths](Weaponsmith.md) can create [weapons](Weapon.md), [trap](Trap.md) components, [bolts](Bolt.md), and [ballista arrowheads](Ballista_arrowhead.md)
- [Armorsmiths](Armorsmith.md) create [armor](Armor.md)
- [Metal crafters](Metal_crafter.md) create [chains](Chain.md) and "Other Objects" ([crafts](Craft.md), [coins](Currency.md), [goblets](Goblet.md)), musical [instrument](Instrument.md) components, as well as performing [studding](Decoration.md)
- [Blacksmiths](Blacksmith.md) create [anvils](Anvil.md), [blocks](Block.md), and all [furniture](Furniture.md) except chains
- [Trappers](Trapping.md) create animal traps.
- [Mechanics](Mechanic.md) create mechanisms.

### Cost of Items

The cost of a [weapon](Weapon.md) or piece of [armor](Armor.md) in metal [bars](Bar.md) can be calculated by using material size/3 and rounding down, with no item costing less than one metal bar. The exception to this is some types of finished goods, which are created in different multiples from a single metal bar, depending on the skill of the [Metal crafter](Metal_crafter.md). The table on the [Melt item](Melt_item.md) page lists the cost of common items and their yields when melted.

### Size<sup>[v0.42.01](../Category/Version_0.42.01.md)</sup>

To create differently sized armor for non-dwarf residents, request it to be made from the workshop as usual. Afterwards, go back to the main workshop menu and look at the details of the issued job. filter for the race you want to make the item for and press enter twice.
