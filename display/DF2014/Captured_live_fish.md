**A captured live fish** is caught using the "capture live fish" command given at a [fishery](Fishery.md). A [dwarf](Dwarf.md) with the [fishing](Fishing.md) labor will then attempt to catch an aquatic [vermin](Vermin.md) live using an available [animal trap](Animal_trap.md). The fish will then be placed into an available [aquarium](Aquarium.md). Unlike normal fishing, which will be done at any suitable location, the "capture live fish" command will **only** capture fish from an explicitly designated [fishing zone](Activity_zone.md#fishing).

Only *vermin* fish can be captured with this method. To capture regular-sized fish, underwater [cage traps](Cage_trap.md) are required. In addition, ordering your dwarves to move a captured regular-sized fish to an aquarium may result in the fish being instantly air drowned due to a bug.<sup>[Bug](#bugs):[1590](https://dwarffortressbugtracker.com/view.php?id=1590)</sup>

Captured [turtles](Pond_turtle.md) and [moghoppers](Moghopper.md) can be used as [pets](Pet.md). A captured moghopper is also used to make five units of [mog juice](Mog_juice.md) using the [fishery](Fishery.md)'s "extract from live fish" command. This [extract](Extract.md) can be used for [cooking](Cooking.md) and [trading](Trading.md).

This task will wait for an available animal trap forever, occupying a fishery when none are available. While the fishery waits, fish cleaners cannot perform their automatic task of preparing raw fish.

Note: a constructed animal trap can not be used unless it is deconstructed. (q-\>x).

Unlike [capturing land vermin](Trapper.md), trapping a fish does *not* fulfill the "doing something exciting" [need](Need.md).
