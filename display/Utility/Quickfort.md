> *Quickfort is now part of the official [DFHack](../Main/DFHack.md) release*.

**Quickfort** is a [utility](https://dwarffortresswiki.org/index.php/v0.34:Utilities) for [fortress mode](../Main/Fortress_mode~2.md) that helps you build fortresses from "blueprint" .csv files (comma separated values). These files are easily created and edited in an app like Excel. Most building-oriented DF commands are supported through the use of multiple .csv files to describe the different phases of DF construction (designation, building, stockpiles, and making adjustments. Recent versions of Quickfort work by converting the blueprint into a native macro for Dwarf Fortress, then executing the macro. This allows for enormously faster playback compared to early versions or DF Designator.

### About

The original idea came from Valdemar’s auto-designation macro. Joel Thornton reimplemented the core logic in Python and extended its functionality with Quickfort 2.0. In (year?) it was implemented as DFHack-native implementation, called [DFHack Quickfort](https://docs.dfhack.org/en/stable/docs/tools/quickfort.html).

### Links

- [The Quickfort Community Blueprints](https://www.mediafire.com/folder/u38qsqr1bq6wu/Community_Quickfort_Blueprints_v2) are a large collection of blueprints, published to remove the last hint of hassle in creating a fortress. You can download the lot without a paid account [here](http://www.mediafire.com/download/n6im1ok6z02n8nc/Community_Quickfort_Blueprints_v2.zip).
- video tutorials - Arumba has made an excellent pair of video tutorials ([part one](https://www.youtube.com/watch?v=pHcXVC2--PI), [part two](https://www.youtube.com/watch?v=AEB946mmNSw)) for quickfort.

Tools that converts images to Quickfort blueprints:

- [ChromaFort](http://www.bay12forums.com/smf/index.php?topic=55025) - Chromafort is a tool designed to complement [Quickfort](../Main/Utilities.md#quickfort), by converting images into quickfort-compatible .csv files. It works with 24-bit bitmap (.bmp) files. There are a number of known issues that can affect any image that is not square, and the size must be an exponent of two (8, 16, 32, 64...); other images may show nonexistent colours and/or come out highly distorted.

- [Picturefort](http://www.bay12forums.com/smf/index.php?topic=138590) - Picturefort is an attempt to make "Chromafort, but *better*" - it performs the same function of converting an image to a [Quickfort](../Main/Utilities.md#quickfort)-compatible .csv file. Unlike Chromafort, Picturefort can handle a large number of image formats (though .bmp or .png are recommended); images can be of any shape and within reason size; and while as of May 2014 it is only available on Windows, there are plans for a Linux version.

- [Symmetricity](http://www.bay12forums.com/smf/index.php?topic=154849.0) - A fortress planner with a focus on multiple planes of symmetry. It can output csv for quickfort. It's early in development so it's probably not suitable for serious use cases.

- [Fortplanner](https://fortplanner.com) - A browser based Quickfort blueprint grid editor. Lets you draw designations, buildings, and stockpiles directly on a grid and export to a Quickfort compatible .csv.
