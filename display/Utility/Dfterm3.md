**Dfterm3** is a remote Dwarf Fortress playing software for multiple users through a web interface. It is a successor to [Dfterm2](Dfterm2.md) ([\[1\]](http://www.bay12forums.com/smf/index.php?topic=50643.0)), which does exactly the same on telnet instead of a web browser.

DFTerm3 is no longer actively developed, but alternatives exist such as [DF Everywhere](http://www.bay12forums.com/smf/index.php?topic=139975).

### Setup

- [Download dfterm3](http://www.bay12forums.com/smf/index.php?topic=129995.0) (currently only Windows builds are provided) or [compile it from source](https://github.com/Noeda/dfterm3/blob/master/README.md).
- Obtain the dfhack plugin, either from the [forum thread](http://www.bay12forums.com/smf/index.php?topic=129995.0) or by [compiling it from source](https://github.com/Noeda/dfhack).
- Set the initial administrator password (in the directory where the dfterm3 executable is located):

Linux/OS X:

```
./dfterm3 --admin-password
```

Windows:

```
dfterm3.exe --admin-password
```

Note that the password will not be visible, but will still be readable by dfterm3.
