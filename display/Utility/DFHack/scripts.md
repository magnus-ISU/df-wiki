# Utility:DFHack/scripts

*[Source](https://dwarffortresswiki.org/index.php/Utility:DFHack/scripts) &middot; revision 231592 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../mirror/wikitext/Utility/DFHack/scripts.wiki)*

---
DFHack is an advanced Dwarf Fortress memory access library and a set of tools and scripts using this library, providing direct object-oriented access to Dwarf Fortress's internals as if it were compiled into the game itself. Releases support versions up through DF 0.40.24 (as of June 3rd, 2015) and some of them have been [backported](http://dwarffortresswiki.org/User:Quietust#DFHack-40d) to earlier versions. It runs on Windows, Linux, and MacOS X. As of June 3rd 2015, the latest version is [DFHack 0.40.24-r3](http://www.bay12forums.com/smf/index.php?topic=139553).

Originally a simple memory hacking tool, DFHack has grown to become a full-fledged unofficial extension of the game itself, adding in functionality where official development has lacked. Due to its open-source and collaborative nature, anyone can add their own contribution to this tool. There are different kinds of contributions:

- Binpatches are raw memory edits that alter the game's behavior, which is usually deduced from disassembling. Their main use is bugfixing or the removal of cumbersome, easily alterable constraints. They can be found in the hack/patches folder.
- Plugins are snippets of C++ code that uses DFHack's library to fix bugs or add functionality. They must be compiled before use and are thus platform and dfhack-version dependent. They can be found in the hack/plugins folder.
- Scripts are files written in a scripting language (usually Lua or Ruby) that when loaded by DFHack fix bugs or add functionality. Contrary to plugins, they are not compiled and can be transferred between any platform. However any change within the DFHack data structures (between versions) may break some of these scripts.

This page's purpose is to provide a comprehensive collection of all the plugins, scripts and binpatches ever written.

- [announce.lua](http://www.bay12forums.com/smf/index.php?topic=137011.msg5076999#msg5076999) - Print an announcement to the screen and the gamelog.
- [df-ai](https://github.com/jjyg/df-ai/) - a script that plays alone in fortress mode.
- [force](https://gist.github.com/Putnam3145/7005776) - Allows forcing of events. Some of them are iffy, some don't work at all. It's mostly functional.
- [hackWish](https://gist.github.com/Putnam3145/8207480) - Use a swanky GUI to create an item with any material and quality.
- [instant transmission](https://gist.github.com/Putnam3145/7021922) - Allows teleportation to units in adventure mode by adventurer. Also gives power level readout.
- [itemsyndrome](https://gist.github.com/Putnam3145/7005730) - Allows items to impart syndromes when equipped.
- [moddableGods](https://gist.github.com/Putnam3145/7005768) - Allows custom gods to be added as hist figures. They do nothing as of now. Might do something funny next version, but nobody knows what exactly.
- [Probability Syndrome](http://www.bay12forums.com/smf/index.php?topic=134774.0) - Run AutoSyndrome commands which honour reaction probabilities.
- [projectileExpansion](https://gist.github.com/Putnam3145/7005764) - Allows a lot of stuff related to projectiles, such as explosions, syndrome addition and script running-on-creatures.
- [rip-heart](https://gist.github.com/warmist/8450238) - removes units heart for a better storage (usually kills in process)
- [shapechange](https://gist.github.com/Putnam3145/7021958) - Allows willful polymorph into arbitrary creature with filtering by ID or size.
- [skillroll](https://gist.github.com/Putnam3145/7839350) - Allows for skills to be considered when running Lua scripts. Probability Syndrome is probably better for most purposes.
- [take-slave](https://gist.github.com/Putnam3145/7035209) - Like hire-guard, but with more transformation. Requires a SLAVE caste for currently played race.
- [teleport](https://gist.github.com/Putnam3145/7243759) - Allows simple teleportation of unit to position. Position can be cursor or hardcoded.
- [trainskill](https://gist.github.com/Devduweb/6409714) - Raises the skill level of a unit.
- [fovcommand](https://gist.github.com/Devduweb/6350270) - Executes a dfhack command on targets within the line of sight of a unit.
- [callsiege](https://gist.github.com/Devduweb/6323075) - Causes a random siege, you can set a probability for this to happen.
- [naturalSkills](https://gist.github.com/Devduweb/6210329) - Make sure creatures have their natural skills.
- [dwarves and points](http://www.bay12forums.com/smf/index.php?topic=135506.msg4925005#msg4925005) - Allows to pick any number of embark dwarves and points.
- [construct-creature](https://gist.github.com/IndigoFenix/8543661) - Allows you to construct creatures with reactions that incorporate the reagent materials into the creature's body. Perfect for robots and golems.
- [slam](https://gist.github.com/IndigoFenix/8543557) - A simple script that slams a creature into the ground at a given velocity. Can cause targets to explode at high enough values.
- [exile](https://gist.github.com/IndigoFenix/8543616) - Sends units away into the wild. Options include fort members, pets, wild animals, invaders, merchants, and diplomats.
- [hfspit](https://gist.github.com/IndigoFenix/8776696) - Creates a pit under the target leading straight to the underworld. Instant death to non-fliers. Very small chance of triggering a demon attack.
- [DFHack spells](http://www.bay12forums.com/smf/index.php?topic=135597.0) - Set of scripts for more complex interaction based spells
- [spawn unit](https://gist.github.com/warmist/8563110) - finally a central place for spawn unit script updates
- [heal unit](https://gist.github.com/warmist/8594614) - heal units script
- [rubble_fluids module](http://www.bay12forums.com/smf/index.php?topic=137011.msg5077002#msg5077002) - Functions for easy fluid and minecart interaction from Lua code.
- [rubble_fluids command](http://www.bay12forums.com/smf/index.php?topic=137011.msg5077002#msg5077002) - Test driver and autoSyndrome command for the rubble_fluids module.
- [whosout](http://www.bay12forums.com/smf/index.php?topic=136725.0) - lists any dorfs who are not in any of the burrows passed as arguments.
- [show-cursed](http://www.bay12forums.com/smf/index.php?topic=136975.0) - list assumed name of any cursed dorfs
- [show-dfhack-version](http://www.bay12forums.com/smf/index.php?topic=136749.0) - outputs dfhack release to the console (put it in your dfhack.init)
- [show-speeds](http://www.bay12forums.com/smf/index.php?topic=136748.msg5045463#msg5045463) - Shows current speed and encumbrance for each citizen.
- [Rendermax](http://www.bay12forums.com/smf/index.php?topic=128487.0), a plugin that implements a lighting system at the graphics level.
- [Dwarven Emigration](http://www.bay12forums.com/smf/index.php?topic=136155.0), a script that allows unhappy dwarves to emigrate with their families.
