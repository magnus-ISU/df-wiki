<br>

Tokens used to define the [descriptive colors](Color.md#color-tokens) used in the game, by dyes, materials and tissues. Not to be confused with the game's [color scheme](Color_scheme.md) that defines what colors are graphically shown in-game.

### Tokens

| Token | Arguments | Usage | Description |
| --- | --- | --- | --- |
| [NAME](#name) | string | Required | What this color will be called in-game. |
| [WORD](#word) | tag | Required | Associates the color with any number of [words](Language_token.md). Historical figures can be named after the color of their [TL_COLOR_MODIFIER](Creature_token~2.md#tl-color-modifier). Seems to be more notable if that description can only be a single color. |
| [RGB](#rgb) | red:green:blue | Required | Decides the exact color value of the color using the additive RGB system. This color is not shown in-game, but when a [randomly](Forgotten_beast.md) [generated](Titan.md) [beast](Demon.md) uses this color, their tile color is defined by an approximation of this<sup>\[[Verify](https://dwarffortresswiki.org/index.php?title=Talk:Descriptor_color_token&action=edit&redlink=1)\]</sup>. Each value can range from 0-255. |
