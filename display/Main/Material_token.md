<br>

Material tokens are used to refer to various types of materials in a wide variety of places. They can take the following forms below.

### Tokens

| Token | Arguments | Description |
| --- | --- | --- |
| [INORGANIC](#inorganic) | MATERIAL_NAME | Specifies a standalone inorganic material defined in the raws, generally a stone or metal. For example, INORGANIC:IRON refers to [iron](Iron.md), and INORGANIC:CERAMIC_PORCELAIN refers to [porcelain](Porcelain.md). The material name can be substituted with USE_LAVA_STONE to randomly select a suitable [lava stone](Inorganic_material_definition_token.md), which is normally [obsidian](Obsidian.md). Specify NONE or NO_MATGLOSS to instead select [magma](Magma.md). |
| [STONE](#stone) | MATERIAL_NAME | Alias for INORGANIC:MATERIAL_NAME, intended for backwards compatibility. |
| [METAL](#metal) | MATERIAL_NAME | Alias for INORGANIC:MATERIAL_NAME, intended for backwards compatibility. |
| [COAL](#coal) | CHARCOAL, COKE, or NO_MATGLOSS | Specifies a material that can be used as fuel - charcoal or coke. Specifying NO_MATGLOSS (**not** NONE) will make it accept "refined coal" in general, matching both charcoal and coke. |
| [CREATURE_MAT](#creature-mat) | CREATURE_ID:MATERIAL_NAME or CREATURE_ID:INDEX### | Specifies a material associated with a specific creature. Examples: CREATURE_MAT:DWARF:SKIN refers to [dwarf](Dwarf.md) skin. Can also specify "INDEX" followed by a 3-digit number to select a material by index instead of by name, where 000 is the first material in that creature. |
| [LOCAL_CREATURE_MAT](#local-creature-mat) | MATERIAL_NAME or INDEX### | Alias for CREATURE_MAT:**CREATURE_ID**:MATERIAL_NAME (or CREATURE_MAT:**CREATURE_ID**:INDEX###), where CREATURE_ID is the creature currently being defined; as such, it can only be used in creature definitions. |
| [PLANT_MAT](#plant-mat) | PLANT_ID:MATERIAL_NAME | Specifies a material associated with a specific plant. Example: PLANT_MAT:BUSH_QUARRY:LEAF refers to [quarry bush](Quarry_bush~2.md) leaves. Unlike CREATURE_MAT, "INDEX###" is **not** permitted. |
| [LOCAL_PLANT_MAT](#local-plant-mat) | MATERIAL_NAME | Alias for PLANT_MAT:**PLANT_ID**:MATERIAL_NAME, where PLANT_ID is the plant currently being defined; as such, it can only be used in plant definitions. Unlike LOCAL_CREATURE_MAT, "INDEX###" is **not** permitted. |
| [GET_MATERIAL_FROM_REAGENT](#get-material-from-reagent) | REAGENT_ID:REACTION_PRODUCT_ID | Specifies a material related to a reagent's material within a [reaction](Reaction.md). REAGENT_ID must match a \[REAGENT\], and REACTION_PRODUCT_ID must either match a \[MATERIAL_REACTION_PRODUCT\] belonging to the reagent's material or be equal to "NONE" to use the reagent's material itself. |
| [MATERIAL_NAME](#material-name) | NONE (ignored) | Specifies one of the hardcoded materials listed below. Note that this goes in the token itself, not arguments (i.e GLASS_GREEN:NONE, not MATERIAL_NAME:GLASS_GREEN). |

Several types of [items](Item_token.md) expect a creature ID and caste ID (e.g. [ANT:SOLDIER](Ant.md)) in place of the material token.

#### Internal Material IDs

It should be noted when using the table below, that you do not place (MATERIAL_NAME:(Your material here)). For example, green glass will be (GLASS_GREEN:NONE).

| # | Token | Information |
| --- | --- | --- |
| -1 | [NONE](#none) | [Unknown material](Unknown_material.md) (light gray, solid), acts as a placeholder for any material. |
| 0 | [INORGANIC](#inorganic) | [Magma](Magma.md) when specified with subtype NONE or NO_MATGLOSS, otherwise a user-defined inorganic material. |
| 1 | [AMBER](#amber) | [Amber](Amber.md) |
| 2 | [CORAL](#coral) | [Coral](Coral.md) |
| 3 | [GLASS_GREEN](#glass-green) | [Green glass](Green_glass~2.md) |
| 4 | [GLASS_CLEAR](#glass-clear) | [Clear glass](Clear_glass.md) |
| 5 | [GLASS_CRYSTAL](#glass-crystal) | [Crystal glass](Crystal_glass.md) |
| 6 | [WATER](#water) | [Water](Water.md), when placed in [buckets](Bucket.md) or when mining out [ice](Ice.md). |
| 7 | [COAL](#coal) | [Coal](Coal.md) - subtype is either COKE or CHARCOAL (or NO_MATGLOSS to match either). |
| 8 | [POTASH](#potash) | [Potash](Potash.md) |
| 9 | [ASH](#ash) | [Ash](Ash.md) |
| 10 | [PEARLASH](#pearlash) | [Pearlash](Pearlash.md) |
| 11 | [LYE](#lye) | [Lye](Lye.md) |
| 12 | [MUD](#mud) | [Mud](Mud.md) |
| 13 | [VOMIT](#vomit) | [Vomit](Vomit.md) |
| 14 | [SALT](#salt) | [Salt](Salt.md) |
| 15 | [FILTH_B](#filth-b) | [Filth](Filth.md) (brown, solid) |
| 16 | [FILTH_Y](#filth-y) | [Filth](Filth.md) (yellow, liquid) |
| 17 | [UNKNOWN_SUBSTANCE](#unknown-substance) | [Unknown substance](Unknown_substance.md) (light gray, liquid) |
| 18 | [GRIME](#grime) | [Grime](Grime.md) |
| 19 - 218 | [CREATURE_1](#creature-1) thru CREATURE_200 | Materials attached to specific types of [creatures](Creature.md). Cannot be specified directly within raws, only used internally. |
| 219 - 418 | [HIST_FIG_1](#hist-fig-1) thru HIST_FIG_200 | Creature materials bound to specific historical figures (e.g. for [vampire](Vampire.md) blood). Cannot be specified directly within raws, only used internally |
| 419 - 618 | [PLANT_1](#plant-1) thru PLANT_200 | Materials attached to specific types of [plants](Plant.md). Cannot be specified directly within raws, only used internally |
| 619 - 658 | [UNUSED01](#unused01) thru UNUSED40 | Placeholders for new hardcoded materials. Cannot be specified directly within raws. |
