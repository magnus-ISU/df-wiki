<br> **World tokens** are used to define the [parameter sets](Advanced_world_generation.md#parameter-sets) used in creating worlds, which are stored in `prefs/world_gen.txt`, though the file might not exist until you save a parameter set. You can change all of these in-game in the world generation menu by entering *Detailed mode*, or by editing the plain-text file directly. For information on generating worlds with particular geographic features, see [Advanced world generation](Advanced_world_generation.md).

World parameters can be read by the [Lua runtime](Lua_scripting.md), stored in `world.param[lowercase token name]`.
