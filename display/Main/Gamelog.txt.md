The **gamelog.txt** is the game's output log file, located in the game's root directory. It stores every [announcement](Announcement.md) and [report](Report.md) available to the player, sorted by oldest to newest. This file is not present in new instances of the game, but rather is automatically created when the game attempts to write something in it but it doesn't exist yet.
