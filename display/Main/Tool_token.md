</td>
<td>
</td>
<td>Permits the tool to be made from any <a href="Bone.md">bone</a>. Default jobs for <a href="Bone.md">bone</a> tools can only be performed by work order. <sup><a href="#bugs">Bug</a>:<a href="https://dwarffortressbugtracker.com/view.php?id=12689">12689</a></sup>

<td> <a href="#ceramic-mat">CERAMIC_MAT</a>
</td>
<td>
</td>
<td>Permits the tool to be made from any material that <code><a href="Material_definition_token.md#is-ceramic">[IS_CERAMIC]</a></code>.
</td></tr>
<tr>
<td> <a href="#description">DESCRIPTION</a>
</td>
<td>
</td>
<td>Allows a string to describe the tool when viewed. The text box can accommodate up to 325 characters until it cuts off, but the spacing of actual sentences puts the realistic limit closer to 300.  Multiple DESCRIPTION tokens can be used in the same tool definition, with each appearing on a new line.
</td></tr>
<tr>
<td> <a href="#glass-mat">GLASS_MAT</a>
</td>

</td>

</td></tr>
<tr>
<td> <a href="#hard-mat">HARD_MAT</a>
</td>
<td>
</td>
<td>Permits the tool to be made from anything with the <code><a href="Material_definition_token.md#items-hard">[ITEMS_HARD]</a></code> token, such as <a href="Wood.md">wood</a>, <a href="Stone.md">stone</a> or <a href="Metal.md">metal</a>.
</td></tr>
<tr>
<td> <a href="#leather-mat">LEATHER_MAT</a>

</td>

</td></tr>
<tr>
<td> <a href="#metal-mat">METAL_MAT</a>
</td>
<td>
</td>
<td>Permits the tool to be made from anything with the <code><a href="Material_definition_token.md#is-metal">[IS_METAL]</a></code> token.

</td>

Connected to the PAPER_SLURRY/PAPER_PLANT reaction classes?<sup>[<a href="https://dwarffortresswiki.org/index.php?title=Talk:Tool_token&amp;action=edit&amp;redlink=1">Verify</a>]</sup>

</td>

<tr>
<td> <a href="#wood-mat">WOOD_MAT</a>
</td>
<td>
</td>
<td>Permits the tool to be made from any <a href="Wood.md">wood</a>.
</td></tr>
<tr>
<td> <a href="#incomplete-item">INCOMPLETE_ITEM</a>
</td>
<td>
</td>
<td>According to Toady, "Won't be used in world gen libraries (to differentiate scrolls from quires). Also put it on bindings, rollers, instr. pieces for completeness/future use".  Used on scroll rollers, book bindings, and quires.
</td></tr>
<tr>
<td> <a href="#default-improvement">DEFAULT_IMPROVEMENT</a>
</td>
<td>
<ul><li>improvement type and subtype (latter only really applicable to SPECIFIC)</li>
<li>tool material flag like <code><a href="Tool_token.md#hard-mat">[HARD_MAT]</a></code> or <code><a href="Tool_token.md#silk-mat">[SILK_MAT]</a></code></li></ul>
</td>
<td>Items that appear in the wild come standard with this kind of improvement. Used on scrolls: [DEFAULT_IMPROVEMENT:SPECIFIC:ROLLERS:HARD_MAT]
<p>Currently bugged, the effect is also applied to everything made in-game. This causes scrolls to have two sets of rollers, for example.
</p>
</td></tr>
<tr>
<td> <a href="#unimprovable">UNIMPROVABLE</a>
</td>
<td>
</td>
<td>Prevents the tool from being <a href="Decoration.md">improved</a>.  Used on honeycombs, scroll rollers, book bindings, and quires.
</td></tr>
<tr>

</td>

<ul><li>num</li></ul>
</td>

</td></tr>
<tr>
<td> <a href="#tile">TILE</a>
</td>

<ul><li>num</li></ul>
</td>
<td>Defines the tile used to represent the tool. Required.
</td></tr>
<tr>
<td> <a href="#inverted-tile">INVERTED_TILE</a>
</td>
<td>
</td>
<td>The background of the tile will be colored, instead of the foreground.
</td></tr>
<tr>
<td> <a href="#no-default-job">NO_DEFAULT_JOB</a>
</td>
<td>
</td>
<td>According to Toady, "only custom reactions are used to make this item". Found on <a href="Scroll.md">scrolls</a> and <a href="Quire.md">quires</a>.
</td></tr>
<tr>
<td> <a href="#tool-use">TOOL_USE</a>
</td>
<td>
<ul><li><a href="Tool_token.md#valid-tool-uses">tool use, see below</a></li></ul>
</td>
<td>Defines the task performed using the tool.
</td></tr>
<tr>
<td> <a href="#furniture">FURNITURE</a>
</td>
<td>
</td>
<td>Allows item to be stored in a <a href="Stockpile.md#furniture-storage">furniture stockpile</a>, and default jobs (unless disabled with <code><a href="Tool_token.md#no-default-job">[NO_DEFAULT_JOB]</a></code>) are considered <a href="Furniture.md">furniture</a>-making tasks instead of <a href="Finished_good.md">crafts</a>.
<p>The jobs for wood and stone will be done at the <a href="Carpenter's_workshop~2.md">carpenter's workshop</a> or <a href="Stoneworker's_workshop.md">stoneworker's workshop</a> instead of the <a href="Craftsdwarf's_workshop~2.md">craftsdwarf's workshop</a>. Likewise, the jobs for metal tools will use the <a href="Blacksmith.md">blacksmith</a> skill instead of <a href="Metal_crafter.md">metal crafter</a>.
</p>
</td></tr>
<tr>
<td> <a href="#shape-category">SHAPE_CATEGORY</a>

<ul><li>shape category</li></ul>
</td>

</td></tr>

</td>

<td> <a href="#material-size">MATERIAL_SIZE</a>

<ul><li>value</li></ul>
</td>

</td></tr>
<tr>
<td> <a href="#attack">ATTACK</a>
</td>
<td>
<ul><li>attacktype:BLUNT or EDGE</li>
<li>contact_area:value</li>

<li>verb2nd:string</li>
<li>verb3rd:string</li>
<li>noun:string</li>
<li>velocity_multiplier:value</li></ul>
</td>
<td>You can have many ATTACK tags and one will be randomly selected for each attack, with EDGE attacks 100 times more common than BLUNT attacks. Required for weapons.
