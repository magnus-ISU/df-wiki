<br>

Item tokens are the first part in defining the target item in [reactions](Reaction.md), containing the item type and subtype. They determine the most basic form of the item, made more specific by [material tokens](Material_token.md). Most item tokens do not have a subtype; for these, either NO_SUBTYPE or NONE **must** be specified.

Nearly all items are made of a [material](Material_token.md), though several types expect a creature ID and caste ID (e.g. [ANT:SOLDIER](Ant.md)) instead.

Actually defining an item in the item raws is done with [item definition tokens](Item_definition_token.md).

### Special use item tokens

In several specific locations, the values below can be substituted for the item type and subtype (and be followed directly by the [material token](Material_token.md)).

| Token | Subtype | Valid Uses | Description |
| --- | --- | --- | --- |
| [ANY_CRAFT](#any-craft) | NONE | [Reaction](Reaction.md) \[REAGENT\] | Matches FIGURINE, AMULET, SCEPTER, CROWN, RING, EARRING, or BRACELET. |
| [ANY_RAW_MATERIAL](#any-raw-material) | NONE | [Reaction](Reaction.md) \[REAGENT\] | Matches POWDER_MISC, BAR, BOULDER, or GLOB. |
| [CRAFTS](#crafts) | NONE | [Reaction](Reaction.md) \[PRODUCT\] | Produces 1-3 items of any type possible to make with the specified material, normally the types FIGURINE, AMULET, SCEPTER, CROWN, RING, EARRING, or BRACELET, however GEM is also possible for some materials and there may be other possible results. The output depends entirely on the material used, and incredibly unusual materials may produce nothing at all, although most vanilla materials will produce GEMs at the very least. |
