# Save version

*[Source](https://dwarffortresswiki.org/index.php/Save_version) &middot; revision 319246 &middot; retrieved 2026-09-12 &middot; [wikitext](../../mirror/wikitext/Main/Save_version.wiki)*

---
Every world in *Dwarf Fortress* contains an internal **save version** ID number to denote the version in which it was last saved, as well as the version in which it was originally generated. When a world is loaded, the game uses this value to determine how to process all of the data it reads - data which didn't exist at the time is generated from scratch (e.g. [hauling routes](https://dwarffortresswiki.org/index.php/v0.34:Minecart), added in version 0.34.08), and data which is no longer used (e.g. [basic thoughts](../DF2014/Thought.md), replaced with emotions in version 0.42.01) gets skipped.

Not all *Dwarf Fortress* releases actually incremented the save version number (especially those which only fixed bugs), and some releases incremented it multiple times (once for each piece of new data stored).

This number normally isn't visible during gameplay, but various tools (such as [DFHack](DFHack.md)) can be used to query it.
