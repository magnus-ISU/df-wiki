**Mod info tokens** are used in a [mod](Mod.md)'s info.txt file.

### Info.txt Tokens

| Token | Arguments | Usage | Description |
| --- | --- | --- | --- |
| [ID](#id) | id | Required | The ID of the mod. This should be unique, with no two mods sharing the same ID. IDs starting with "vanilla\_" are reserved for vanilla raws. |
| [NUMERIC_VERSION](#numeric-version) | integer | Required | An **integer** version number for the mod. Must be greater than or equal to EARLIEST_COMPATIBLE_NUMERIC_VERSION. "Integer" here means 0, 1, 2, and so on. Negatives are allowed. Anything that is not an integer will not work; 0.2 will be read as "0". |
| [DISPLAYED_VERSION](#displayed-version) | string | Required | The version of the mod, as displayed in-game. This is only a display, and will have no effect. |
| [EARLIEST_COMPATIBLE_NUMERIC_VERSION](#earliest-compatible-numeric-version) | integer | Required | The earliest compatible numeric version of the mod. Installed mods are automatically updated, if a later compatible version is available. **This must be at most the same as NUMERIC_VERSION, and doing otherwise will result in an error.** |
| [EARLIEST_COMPATIBLE_DISPLAYED_VERSION](#earliest-compatible-displayed-version) | string | Required | The earliest compatible numeric version, as displayed in-game. |
| [AUTHOR](#author) | string | Required<sup>\[[Verify](https://dwarffortresswiki.org/index.php/Talk:Mod_info_token)\]</sup> | The name of the author (usually you). |
| [NAME](#name) | string | Required<sup>\[[Verify](https://dwarffortresswiki.org/index.php/Talk:Mod_info_token)\]</sup> | The name of the mod. |
| [DESCRIPTION](#description) | string |  | A description of the mod, shown in the mod loading screen. |
| [REQUIRES_ID](#requires-id) | string |  | Mod cannot be used unless mod with given ID is also loaded. |
| [REQUIRES_ID_BEFORE_ME](#requires-id-before-me) | string |  | Mod cannot be used unless mod with given ID is earlier in the mod load list. |
| [REQUIRES_ID_AFTER_ME](#requires-id-after-me) | string |  | Mod cannot be used unless mod with given ID is later in the mod load list. |
| [CONFLICTS_WITH_ID](#conflicts-with-id) | string |  | Mod cannot be used if mod with given ID is also loaded. |
