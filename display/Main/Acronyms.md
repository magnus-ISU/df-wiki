**Acronyms** used in *Dwarf Fortress*.

| Acronym | Meaning |
| --- | --- |
| **AG** | Above Ground (as opposed to UG, UnderGround). Often refers to [crops](Crop.md), but could describe anything. |
| **AM** | Adventure Mode, solo character play in an extended world map. |
| **DAS** | [Dwarven Atom Smasher](Dwarven_Atom_Smasher.md). |
| **DF** | *Dwarf Fortress*, the game this wiki is based on. |
| **FB** | [Forgotten beast](Forgotten_beast.md). |
| **FM** | Fortress Mode; game play with many, perhaps hundreds of [dwarves](Dwarf.md) in a single [region](Region.md). |
| **GCS** | [Giant Cave Spider](Giant_cave_spider.md). |
| **HFS** | [Hidden Fun Stuff](Hidden_Fun_Stuff.md); fell things awaken when dwarves dig too deep. |
| **QSP** | [Quantum Stockpile](Quantum_Stockpile.md). |
| **RL** | Real Life; not the game. |
| **RNG** | Random Number/Name Generator/God. |
| **UG** | Underground (as opposed to AG, Above Ground). Often refers to [crops](Crop.md), but could describe anything. |

### Non-acronyms

- **[Fun](Fun.md)** - Euphemism for the extreme or unexpected, also the inevitable fortress loss.
