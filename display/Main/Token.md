<br> In *Dwarf Fortress*, a **token** is a piece of text that defines the properties of an object. An "object" could be a material, a type of tissue, an organ, a piece of armor, a creature, a biome, a civilization, or anything else in the game; a "property" could be how large something is, what it is made from, its melting temperature, its name, its biome preference (for civilizations) or anything else that makes it unique. All information associated with the properties of an object in the game is defined using tokens. Tokens are used in the [raws](Raws.md), which can be easily [modified](Modding.md), allowing users to create (and distribute) new content.

> - [Audio](Audio.md) tokens define audio metadata, and the triggers to play music and sound.
> - [Biome tokens](Biome_token.md) reference [environments](Biome.md) for creatures, plants and [entities](Civilization.md).
> - [Building tokens](Building_token.md) define buildings.
> - [Body tokens](Body_token.md) determine bodily structure and materials.
>   - [Bodygloss](Bodygloss.md) tokens perform a single-word substitution of a creature's body parts.
> - [Body detail plan tokens](Body_detail_plan_token.md) define some details of a body, similar to body tokens.
> - [Creature tokens](Creature_token~2.md) determine the properties of creatures, while [Creature variation tokens](Creature_variation_token.md) are used to modify creatures.
> - [Descriptor color tokens](Descriptor_color_token.md) - not to be confused with [color schemes](Color_scheme.md) - define colors used in text-based descriptions, while [Descriptor pattern tokens](Descriptor_pattern_token.md) define color patterns, and [Descriptor shape tokens](Descriptor_shape_token.md) define [shapes](Shape.md).
> - [Entity tokens](Entity_token.md) define entities, or [civilizations](Civilization.md).
>   - [Position tokens](Position_token.md) define [noble](Noble.md) titles and administrative positions in entities.
> - [Graphics tokens](Graphics_token.md) define tile-based [graphics](Graphics.md).
> - [Item tokens](Item_token.md) reference the most basic form of items (made specific by material tokens). Item tokens are mainly used in [reactions](Reactions.md).
> - [Item definition tokens](Item_definition_token.md) are used to define various types of item.
>   - [Ammo tokens](Ammo_token.md) define ammunition, such as arrows and bolts.
>   - [Armor tokens](Armor_token.md) define armor.
>   - [Instrument tokens](Instrument_token.md) define instruments.
>   - [Trap component tokens](Trap_component_token.md) define weapons used in traps.
>   - [Tool tokens](Tool_token.md) define tools, similar to weapon tokens.
>   - [Weapon tokens](Weapon_token.md) define weapons.
> - [Interaction tokens](Interaction_token.md) define interactions.
> - [Labor tokens](Labor_token.md) reference labors.
> - [Language tokens](Language_token.md) define a language's vocabulary. Since fictional languages in *Dwarf Fortress* are currently only used in names, language tokens do not define grammar.
> - [Material tokens](Material_token.md) are used to refer to materials, similar to item tokens.
> - [Material definition tokens](Material_definition_token.md) are used to define materials that appear in a number of object types.
>   - [Inorganic material definition tokens](Inorganic_material_definition_token.md) are specific to defining inorganic materials.
> - [Plant tokens](Plant_token.md) define plants.
> - [Reaction](Reaction.md) tokens define crafting recipes.
> - [Skill tokens](Skill_token.md) reference skills.
> - [Speech files](Speech_file.md) define strings used for certain lines of dialog and book titles.
> - [Syndrome tokens](Syndrome_token.md) define syndromes (ie: conditions, diseases, bonuses and maluses).
> - [Tissue definition tokens](Tissue_definition_token.md) define tissues.
> - [Unit type tokens](Unit_type_token.md) reference by tilesets and entities, for purposes of professions and the like.
> - [World tokens](World_token.md) are used in [advanced world generation](Advanced_world_generation.md).

Also note the `[LOG_CURRENT_ENTRY]` token, available for all object types. For information regarding use, see [Modding#Modifying the vanilla objects](Modding.md#modifying-the-vanilla-objects).
