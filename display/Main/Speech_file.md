<br> **Speech files**, also known as **text sets**, are text files that define sentences which can be spoken by people in [adventure mode](Adventure_mode~2.md) and phrases used to name [books](Books.md). Most of them are found in the `data/vanilla/vanilla_text/objects` folder, though the creature specific files can be found in `data/vanilla/vanilla_creatures/objects`. Like other raw files, mods can replace or introduce new sentences.

### List of Tokens

Speech files can contain tokens in square brackets (`[]`), which are replaced with context-specific strings before the speech is displayed.

#### Book title tokens

These tokens are used for [book titles](Book.md#titles) and specific examples of [performances](Performer.md) such as songs, poems, or dances. It is unknown if the generating tokens can be used in other text sets to generate random words.

| Token | Meaning | Example |
| --- | --- | --- |
| [NAME](#name) | Inserts a name relevant to the book's [topic](Topic.md), or a random noun for art and star charts. Notably, these may or may not be plural and/or have an article. | The [Tower](Tower_(necromancy).md), The [Tree](Forest_retreat.md), [Bronzemurder](https://dwarffortresswiki.org/index.php/v0.31:Stories/Bronzemurder), [Likot Ubendeb](Book.md#history), [Animal Behaviours](Book.md#nature) |
| [NO_ART_NAME](#no-art-name) | "No article name." As [NAME](Speech_file.md#name), but never has an article. | Tower, Tree, Bronzemurder, Likot Ubendeb, Animal Behaviours |
| [NOUN](#noun) | A random noun pulled from [language_words.txt](Language_words.txt.md) or a hardcoded list. May or may not be plural. | Despair, Roots, Scrolls, Wheel-and-axles |
| [ADJ](#adj) | A random adjective from [language_words.txt](Language_words.txt.md). | Boyish, Inky, Angry, Bronzed |
| [ANY_AGE](#any-age) | References an [age](Calendar.md#ages) that has occurred in the world's [history](Legends.md). | The Age Of Legends, The Age Of Hill Titan and Dragon |
| [ANY_PRONOUN](#any-pronoun) | Chosen from among singular and plural subject pronouns (not "Us" or "Them"). | He, She, We, They |
| [PHRASE](#phrase) | A random phrase of a noun/pronoun, a verb, and some other words. | The Fool Laughs, The Day Can Say It In The End, It Foretells Afterwards, The Day Mourns |

#### Dialogue tokens

Character dialogue uses its own set of tokens to reference data. Scopes identify participants in a conversation and various forms of background information. They can be nested within each other in various cases. If the scopes refer to a historical object, it is expected \[verify\] that not using the TRANS_NAME argument will display the untranslated name. Strings are the arguments for scopes, outputting a specific word based on the conversation data. In certain files, they are used by themselves with an implied scope.

| Token | Type | Meaning |
| --- | --- | --- |
| [SPEAKER](#speaker) | base scope | The person speaking the dialogue. |
| [AUDIENCE](#audience) | base scope | The person receiving the dialogue. Has buggy behavior without a defined audience, such as when shouting out to everyone. |
| [CONTEXT](#context) | base scope | Holds additional information depending on the subject of conversation. Must use HIST_FIG as its argument to retrieve personal info from a creature that isn't present. |
| [HIST_FIG](#hist-fig) | scope | Usually written as \[CONTEXT:HIST_FIG\], this refers to a historical figure referenced by the speaker. |
| [PLACE](#place) | scope | A location, such as a biome. |
| [SITE](#site) | scope | A site given by the context. |
| [HF_LINK](#hf-link) | scope | Looks for historical figures [associated](Relationship.md) with the scope. |
| [DEITY](#deity) | scope | An argument for \[HF_LINK\], in this case referring to a (presumably, devoutly worshipped) [deity](Deity.md). |
| [TRANS_NAME](#trans-name) | string | The full translated name of the referenced object. |
| [FIRST_NAME](#first-name) | string | The first name of the referenced creature. |
| [PRO_SUB](#pro-sub) | string | The referenced creature's subject pronoun (she, he, it). |
| [PRO_OBJ](#pro-obj) | string | The referenced creature's object pronoun (her, him, it). |
| [PRO_POS](#pro-pos) | string | The referenced creature's possessive pronoun (her, his, its). |
| [ABSTRACT_BUILDING](#abstract-building) | string | The first name of the referenced creature. |
| [RACE](#race) | string | The [name](Creature_token~2.md#name) of the context's species. |
| [NUMBER](#number) | string | A number (expressed as plain text rather than numerals?). |
| [ORDINAL](#ordinal) | string | An ordinal number, such as first or second. |
| [UNIT_NAME](#unit-name) | string | The [unit type](Unit_type_token.md) of the referenced creature. |
| [ARCH_ELEMENT](#arch-element) | string | An architectural element given by the context. |
| [ABSTRACT_BUILDING](#abstract-building) | string | A named building given by the context. |
| [JUSTIFICATION](#justification) | string | A [justification](Speech_file.md#justification-antithetical) chosen by the context. |
| [DEF_SPHERE](#def-sphere) | string | A divine [sphere](Sphere.md) chosen by the context. |
| [RANDOM_DEF_SPHERE](#random-def-sphere) | string | A random [sphere](Sphere.md) associated with the scope. |
| [FAMILY_RELATIONSHIP](#family-relationship) | string | The [relationship](Relationship.md) given by the context. |
