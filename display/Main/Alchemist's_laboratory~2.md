In very old versions of *Dwarf Fortress*, an **alchemist's laboratory** was a [workshop](Workshop.md) used to make bars of [soap](Soap.md) (then a simple [trade good](Caravan.md)) from [lye](Lye.md) and [tallow](Tallow.md). To build an alchemist's laboratory, you had to have three clear [glass](Glass.md) [vials](Vial.md). The workshop's function was taken over by the dedicated [soap maker's workshop](Soap_maker's_workshop.md) in version 0.31.01, and the workshop, the [skill](Alchemist.md), and the [labor](Alchemy.md) were buried from view in the game files. [Toady One](Toady_One.md) [plans to eventually return](http://www.bay12games.com/media/df_talk_8_transcript.html) the workshop to the game in a different form, but for now the alchemist's laboratory languishes in the game's code graveyard.
