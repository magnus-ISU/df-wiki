<br>

These were tokens used when adding entries under \[CREATURE_GRAPHICS\] in the graphics.txt file. Graphics for the Premium release use an updated system of [Graphics tokens](Graphics_token.md).

### Tokens

| Token | Notes |
| --- | --- |
| [DEFAULT](#default) | Standard creature |
| [ADVENTURER](#adventurer) | Used when playing the creature as an adventurer(?) |
| [LAW_ENFORCE](#law-enforce) | Presumably used by members of the squad led by a position responsible for LAW_ENFORCEMENT (i.e. fortress guards) |
| [TAX_ESCORT](#tax-escort) | Presumably used by members of the squad led by a position responsible for ESCORT_TAX_COLLECTOR (currently nobody) |
| [ANIMATED](#animated) | Animated (zombie/skeleton) version of the creature |
| [GHOST](#ghost) | Ghostly version of the creature |
