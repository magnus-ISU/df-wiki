#### Profession Categories

Layered graphics only use profession categories rather than individual professions. These are:

- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) STONEWORKER
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) MINER
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) METALSMITH
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) ENGINEER
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) FARMER
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) WOODWORKER
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) JEWELER
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) RANGER
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) STANDARD (i.e. "Peasant". Also includes some invader & visitor professions.)
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) CRAFTSMAN
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) FISHERY_WORKER
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) MERCHANT
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) CHILD
- ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) NONE (applies to anything not included above - doctors, bards, military, etc. Note that this is distinct from having no profession condition; it will apply ONLY to NONE units.)

Noble positions do not affect the categorization; a craftsdwarf appointed to mayor will still use the layers designated for `CRAFTSMAN`.
