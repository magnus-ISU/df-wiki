**Lay pewter** is an [alloy](Alloy.md) that can created from [bars](Bar.md) of metal, at a [smelter](Smelter.md), using the following recipe:

- 2 [Tin](Tin.md) [bars](Bar.md) + 1 [Copper](Copper.md) bar + 1 [Lead](Lead.md) bar

Unlike [trifle pewter](Trifle_pewter~2.md) and [fine pewter](Fine_pewter.md), lay pewter *cannot* be smelted directly from [ore](Ore.md).

Lay pewter has a base value of 3, which would make it preferable over its ingredient metals for creating objects of [value](Value.md), since all of its ingredients have a value of only 2. However, with the same ingredients (in a different formula) you get more value from making [trifle pewter](Trifle_pewter~2.md) or, better still, [bronze](Bronze.md) or [fine pewter](Fine_pewter.md), and using lead as-is (separately).

When using classic ASCII graphics, lay pewter is notable for producing [bars](Bar.md), [furniture](Furniture.md) and [crafts](Crafts.md) that appear in-game as teal-colored, a color shared only by [clear glass](Clear_glass.md) and [spore tree](Spore_tree.md) wood.

Technically *(i.e. "in real life")*, lay pewter is [trifle pewter](Trifle_pewter~2.md) that has been cut with [lead](Lead.md); it is less valuable, but you get more of it.
