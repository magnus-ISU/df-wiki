DFHack-added panel for managing civilian alerts

A **civilian alert** was a [military](Military.md) alert that confined all civilians (and animals) to a specific set of [burrows](Burrow.md).

The current version of vanilla Dwarf Fortress does not provide an interface for managing civilian alerts, however the underlying functionality *is* still present and perfectly usable. [DFHack](DFHack.md) exposes a single civilian alert state via the **gui/civ-alert** tool (on by default in Premium version), with the [burrows](Burrow.md) being configurable from a button which appears when the [![Ui q.png](https://dwarffortresswiki.org/images/3/39/Ui_q.png)](https://dwarffortresswiki.org/index.php/File:Ui_q.png)q [Squad](Squad.md) menu is opened.

Without using DFHack, the same effect can easily be reproduced via the [Burrows](Burrows.md) menu (see [Suspending Burrows](Burrows.md#suspending-burrows)).
