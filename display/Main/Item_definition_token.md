<br> **Item definition tokens** are used in item definitions in the raws.

Item types:

- ITEM_AMMO - [ammo token](Ammo_token.md)
- ITEM_ARMOR - [armor-type armor token](Armor_token.md)
- ITEM_FOOD - see below
- ITEM_GLOVES - [gloves-type armor token](Armor_token.md)
- ITEM_HELM - [helm-type armor token](Armor_token.md)
- ITEM_INSTRUMENT - [instrument token](Instrument_token.md)
- ITEM_PANTS - [pants-type armor token](Armor_token.md)
- ITEM_SHIELD - [shield-type armor token](Armor_token.md)
- ITEM_SHOES - [shoes-type armor token](Armor_token.md)
- ITEM_SIEGEAMMO - see below
- ITEM_TOOL - [tool token](Tool_token.md)
- ITEM_TOY - see below
- ITEM_TRAPCOMP - [trap component token](Trap_component_token.md)
- ITEM_WEAPON - [weapon token](Weapon_token.md)

### Toy tokens

| Token | Arguments | Description |
| --- | --- | --- |
| [NAME](#name) | singular:plural | What this item will be called in-game. |
| [HARD_MAT](#hard-mat) |  | Presumably prevents the item from being made from cloth, silk, or leather, present on everything but puzzleboxes and drums. Appears to work backwards for [strange moods](Strange_mood.md). |

### Siege ammo tokens

| Token | Arguments | Description |
| --- | --- | --- |
| [NAME](#name) | singular:plural | What this item will be called in-game. |
| [CLASS](#class) |  | Specifies what type of siege engine uses this ammunition. Currently, only BALLISTA is permitted. |

### Food tokens

| Token | Arguments | Description |
| --- | --- | --- |
| [NAME](#name) | singular:plural | What this item will be called in-game. |
| [LEVEL](#level) |  | Specifies the number of ingredients that are used in this type of prepared meal - 2 for Easy, 3 for Fine, 4 for Lavish. Defaults to 2. |

For example, see [item_food.txt](https://github.com/DF-Wiki/DFRawFunctions/blob/master/raws/v50/item_food.txt)
