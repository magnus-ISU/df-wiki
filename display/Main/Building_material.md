**Building materials** are objects which can be used to build [workshops](Workshop.md), [constructions](Construction.md), and other types of [buildings](Building.md). Most jobs which expect building materials also expect them to be non-[economic](Economic.md).

The following item types can be used as building materials:

- [Stone](Stone.md)
- [Bar](Bar.md)
- [Block](Block.md)
- [Log](Log.md)
