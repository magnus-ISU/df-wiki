<br>

**Building tokens** control the functionality of custom [buildings](Building.md).

All custom buildings are defined as objects of type BUILDING_WORKSHOP or BUILDING_FURNACE; [workshops](Workshop.md) show up in the Build \> Workshops ([![Ui b.png](https://dwarffortresswiki.org/images/b/b1/Ui_b.png)](https://dwarffortresswiki.org/index.php/File:Ui_b.png)b[![Ui bo.png](https://dwarffortresswiki.org/images/a/aa/Ui_bo.png)](https://dwarffortresswiki.org/index.php/File:Ui_bo.png)o) menu, while [furnaces](Furnace.md) show up in the Build \> Workshops \> Furnaces ([![Ui b.png](https://dwarffortresswiki.org/images/b/b1/Ui_b.png)](https://dwarffortresswiki.org/index.php/File:Ui_b.png)b[![Ui bo.png](https://dwarffortresswiki.org/images/a/aa/Ui_bo.png)](https://dwarffortresswiki.org/index.php/File:Ui_bo.png)o[![Ui bou.png](https://dwarffortresswiki.org/images/9/90/Ui_bou.png)](https://dwarffortresswiki.org/index.php/File:Ui_bou.png)u) menu.

You also must add any new custom buildings to the [civilization](Entity_token.md) that you want to use it.

Additionally, furnaces must be designed by an [mason](Mason.md) before being constructed (and will gain [quality](Quality.md) accordingly), though they will always use the labor(s) specified in the building definition, rather than ones based on the materials being used.

### Item Modifiers

Building items have many of the same modifiers as [reagents](Reactions.md#modifiers) in custom reactions.

| Token | Meaning |
| --- | --- |
| \[ [ANY_BONE_MATERIAL](#any-bone-material)\] | Item material must have the \[BONE\] token. |
| \[ [ANY_HORN_MATERIAL](#any-horn-material)\] | Item material must have the \[HORN\] token. |
| \[ [ANY_LEATHER_MATERIAL](#any-leather-material)\] | Item material must have the \[LEATHER\] token. |
| \[ [ANY_PEARL_MATERIAL](#any-pearl-material)\] | Item material must have the \[PEARL\] token. |
| \[ [ANY_PLANT_MATERIAL](#any-plant-material)\] | Item material must be subordinate to a PLANT object. |
| \[ [ANY_SHELL_MATERIAL](#any-shell-material)\] | Item material must have the \[SHELL\] token. |
| \[ [ANY_SILK_MATERIAL](#any-silk-material)\] | Item material must have the \[SILK\] token. |
| \[ [ANY_SOAP_MATERIAL](#any-soap-material)\] | Item material must have the \[SOAP\] token. |
| \[ [ANY_STRAND_TISSUE](#any-strand-tissue)\] | Item is made of a tissue having \[TISSUE_SHAPE:STRANDS\], intended for matching hair and wool. Must be used with \[USE_BODY_COMPONENT\]. |
| \[ [ANY_TOOTH_MATERIAL](#any-tooth-material)\] | Item material must have the \[TOOTH\] token. |
| \[ [ANY_YARN_MATERIAL](#any-yarn-material)\] | Item material must have the \[YARN\] token. |
| \[ [BUILDMAT](#buildmat)\] | Item must be a general [building material](Building_material.md) - BAR, BLOCKS, BOULDER, or WOOD. |
| \[ [CAN_USE_ARTIFACT](#can-use-artifact)\] | Item can be an Artifact. |
| \[ [CONTAINS_LYE](#contains-lye)\] | Item must be a BARREL or TOOL which contains at least one item of type LIQUID_MISC made of LYE. |
| \[ [EMPTY](#empty)\] | If the item is a container, it must be empty. |
| \[ [FIRE_BUILD_SAFE](#fire-build-safe)\] | Item material must be stable at temperatures below 11000. Only works with items of type BAR, BLOCKS, BOULDER, WOOD, and ANVIL - all others are considered unsafe. |
| \[ [GLASS_MATERIAL](#glass-material)\] | Item material must have the \[IS_GLASS\] token. All 3 types of [glass](Glass.md) have this token hardcoded. |
| \[ [GROWN_NOT_CRAFTED](#grown-not-crafted)\] | Item must be a GROWN wooden item, such as a "grown wooden sword" from an Elven caravan. |
| \[ [HAS_MATERIAL_REACTION_PRODUCT](#has-material-reaction-product):X\] | Item's material has a \[MATERIAL_REACTION_PRODUCT\] token with the appropriate ID. |
| \[ [HAS_TOOL_USE](#has-tool-use):X\] | Item must be a [tool](Tool.md) with the specific TOOL_USE value. The item type must be TOOL:NONE for this to make any sense. |
| \[ [MAGMA_BUILD_SAFE](#magma-build-safe)\] | Item material must be stable at temperatures below 12000. Only works with items of type BAR, BLOCKS, BOULDER, WOOD, and ANVIL - all others are considered unsafe. |
| \[ [METAL_ORE](#metal-ore):X\] | Item material must be an ore of the specified metal. |
| \[ [MIN_DIMENSION](#min-dimension):X\] | Item's dimension must be at least this large. The item type must be BAR, POWDER_MISC, LIQUID_MISC, DRINK, THREAD, or CLOTH for this to work. |
| \[ [NO_EDGE_ALLOWED](#no-edge-allowed)\] | Item must not have an edge, so must be blunt. Sharp stones (produced using knapping) and most types of weapon/ammo can not be used with this token. |
| \[ [NOT_CONTAIN_BARREL_ITEM](#not-contain-barrel-item)\] | If the item is a container, it must not contain [lye](Lye.md) or [milk](Milk.md). Not necessary if specifying \[EMPTY\]. |
| \[ [NOT_ENGRAVED](#not-engraved)\] | Item can not be engraved. For example, a memorial slab can not be engraved. |
| \[ [NOT_WEB](#not-web)\] | Item must be collected (to distinguish silk thread from webs). Only makes sense for items of type THREAD. |
| \[ [POTASHABLE](#potashable)\] (Deprecated) | Alias for \[CONTAINS_LYE\]. |
| \[ [REACTION_CLASS](#reaction-class):X\] | Item's material has a \[REACTION_CLASS\] token with the appropriate ID. |
| \[ [UNROTTEN](#unrotten)\] | Item must not be rotten, mainly for organic materials. |
| \[ [USE_BODY_COMPONENT](#use-body-component)\] | Item must be a body part (CORPSE or CORPSEPIECE). |
| \[ [WEB_ONLY](#web-only)\] | Item must be undisturbed (to distinguish silk thread from webs). Only makes sense for items of type THREAD. |
| \[ [WORTHLESS_STONE_ONLY](#worthless-stone-only)\] | Item material must be non-[economic](Economic.md). |
