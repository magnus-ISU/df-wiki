Dwarf Fortress 50.03 was released as a [Premium version](../Premium_version.md) only.

> One more quick release to handle additional stability issues. This version also includes 72 new werebeast tiles, some changes to ambience, and a start to quality of life additions with the ability to select more materials at once when building constructions.
> — Toady One, December 12, 2022

> Small note from Kitfox: if your save was previously corrupting and crashed, it probably cannot be revived, sorry. Many of these crashing errors caused garbage to be inserted into the save, which now is irreparable. If you can reload to an autosave, that's more likely to work. Otherwise, you'll have to start a new fort. Sorry! Thanks!
> — Kitfox Games, December 12, 2022

- [Patch notes on Steam](https://store.steampowered.com/news/app/975370/view/3631620553397903591)

### Major bug fixes

- Fixed save corruption from manual saves with case mismatch.
- Fixed crash when sorting [pets/livestock](../Creature.md#livestock-and-domestic-animals) by domestication status.
- Fixed crash when removing [burrows](../Burrow.md) from a scrollable burrow list.
- Fixed crash related to storing objects in recently deleted [location](../Location.md) zones.
- Fixed crash on [squad equipment](../Squad.md#equipping-soldiers) screen when there are multiple traveling squads.
- Fixed crash related to removing objects from [display cases/pedestals](../Display_furniture.md).
- Fixed crash from looking at Groups for certain [consorts](../Consort.md).

### Graphics additions/changes

- New graphics for [werebeasts](../Werebeast.md).

### Audio additions/changes

- Updated [forest](../Forest.md), [grassland](../Grassland.md), [rainforest](../Rainforest.md), [siege](../Siege.md) [ambiences](../Ambience.md).
- Added new wild ambience, moved old wild ambience to [terrifying](../Terrifying.md) areas.
- Replaced siege horns with something less intense.

### Other bug fixes/tweaks

- Added ability to add/remove every item of a given material when [building](../Construct.md) structures that require multiple items.
- Holding a navigation key no longer recenters the screen during string entry.
- Now displays remove construction [designation](../Designation.md) when designated instead of requiring unpause.
