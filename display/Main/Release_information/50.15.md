> We have a Fortress Mode patch this week, with a bunch of fixes and tweaks and most notably with the new container graphics. See exactly what's inside your barrels and boxes for easy sorting

> We are still working on [Adventure Mode](../Adventurer_mode.md) things but won't have a patch for a few weeks which means this will be our last update before the holidays. But not to worry, it will be coming VERY SOON! When Adventure Mode leaves beta, it will unify both branches so a lot of upgrades in Adventure Mode will be making their way to [Fort Mode](../Dwarf_fortress_mode~2.md) as well. We hope you have a relaxing and restful holiday!

— Kitfox and Bay 12 Games, December 12, 2024

- [Patch notes on Itch.io](https://kitfoxgames.itch.io/dwarf-fortress/devlog/849612/fortress-mode-update-5015)
- [Patch notes on Steam](https://store.steampowered.com/news/app/975370/view/591757425095213080)

### Graphics additions/changes

- Expanded graphics for [containers](../Storage.md)
- Added ability to view worn [clothing](../Clothing.md) by [dye](../Dye.md) or by [profession](../Profession.md)
- [Shields](../Shield.md) in right arms displayed in correct order

### Major bug fixes

- Fixed crash in Linux related to object pools

### Other bug fixes/tweaks

- Added some safeguards to ages of generated [migrant](../Migrant.md) children
- Made tutorial close button behave consistently when tutorial is minimized
- Made the agitation decay setting work properly
- Removed case sensitivity on unit filters
- Fixed some issues with list sorting
- Fixed crash related to possible null [building](../Building.md) in sheets
- Fixed a crash with [creature variation](../Creature_variation_token.md) mods
- Fixed some threading issues in unit loops
- Fixed problem with [mod](../Mod.md) version compatibility setting
- Fixed command line [world generation](../World_generation.md)
- Made game respect [caste](../Caste.md) population ratio in more places
- Fixed some possible null pointer references
- Added more information to crash log headers
