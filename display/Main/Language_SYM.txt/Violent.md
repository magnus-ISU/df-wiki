### Usage

[Legendary beings](../Historical_figure.md), such as a [bronze colossus](../Bronze_colossus.md) or a [minotaur](../Minotaur.md), associated with the [spheres](../Sphere.md) of chaos, nightmares, revenge, valor, or war will have words from this symbol in their name.

Most [cultures](../Entity.md) use this as [subsymbol](../Entity_token.md#subselect-symbol) for describing [war](../War.md) and other historical conflicts.

### SYMBOL:VIOLENT

This is the **\[SYMBOL:VIOLENT\]** section of the [language_SYM.txt](../Language_SYM.txt.md) raw file. The file defines categories of words, for use with \[SELECT_SYMBOL\] and \[CULL_SYMBOL\] arguments in the corresponding entity file to create various pool of words available for procedural generation of game content (for example, Dwarf names). See [Language#language_SYM.txt](../Language.md#language-symtxt) and [Entity_token](../Entity_token.md) for more details.

#### Examples

- \[SELECT_SYMBOL:VIOLENT\]
- \[CULL_SYMBOL:VIOLENT\]

#### Accented characters

The language files are saved in [code page 437](http://en.wikipedia.org/wiki/Code_page_437) encoding. The accented characters in the language files look like nonsense when interpreted as ASCII or ISO 8859-1, which are often the default. On Windows, viewing the language file with the Terminal font is an easy way to see it correctly.
