### Usage

All [cultures](../Entity.md) with a defined [language](../Language.md) are tagged so they [won't use](../Entity_token.md#cull-symbol) words from this symbol in their names.

### SYMBOL:NEGATOR

This is the **\[SYMBOL:NEGATOR\]** section of the [language_SYM.txt](../Language_SYM.txt.md) raw file. The file defines categories of words, for use with \[SELECT_SYMBOL\] and \[CULL_SYMBOL\] arguments in the corresponding entity file to create various pool of words available for procedural generation of game content (for example, Dwarf names). See [Language#language_SYM.txt](../Language.md#language-symtxt) and [Entity_token](../Entity_token.md) for more details.

#### Examples

- \[SELECT_SYMBOL:NEGATOR\]
- \[CULL_SYMBOL:NEGATOR\]

#### Accented characters

The language files are saved in [code page 437](http://en.wikipedia.org/wiki/Code_page_437) encoding. The accented characters in the language files look like nonsense when interpreted as ASCII or ISO 8859-1, which are often the default. On Windows, viewing the language file with the Terminal font is an easy way to see it correctly.
