### Usage

[Legendary beings](../Historical_figure.md), such as a [bogeyman](../Bogeyman.md) or a [nightmare](../Nightmare.md), associated with the [sphere](../Sphere.md) of misery will have words from this symbol in their name.

Alongside [DEATH](Death.md), [EVIL](Evil.md), and [UGLY](Ugly.md), NEGATIVE is one of the possible [subsymbols](../Entity_token.md#subselect-symbol) available to [evil biomes](../Surroundings.md#evil).

Most [cultures](../Entity.md), except [goblins](../Goblin.md), [won't use](../Entity_token.md#cull-symbol) words from this symbol in their names.

### SYMBOL:NEGATIVE

This is the **\[SYMBOL:NEGATIVE\]** section of the [language_SYM.txt](../Language_SYM.txt.md) raw file. The file defines categories of words, for use with \[SELECT_SYMBOL\] and \[CULL_SYMBOL\] arguments in the corresponding entity file to create various pool of words available for procedural generation of game content (for example, Dwarf names). See [Language#language_SYM.txt](../Language.md#language-symtxt) and [Entity_token](../Entity_token.md) for more details.

#### Examples

- \[SELECT_SYMBOL:NEGATIVE\]
- \[CULL_SYMBOL:NEGATIVE\]

#### Accented characters

The language files are saved in [code page 437](http://en.wikipedia.org/wiki/Code_page_437) encoding. The accented characters in the language files look like nonsense when interpreted as ASCII or ISO 8859-1, which are often the default. On Windows, viewing the language file with the Terminal font is an easy way to see it correctly.
