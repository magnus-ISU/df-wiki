### Usage

[Legendary beings](../Historical_figure.md) associated with the [spheres](../Sphere.md) of family, festivals, hospitality, or labor will have words from this symbol in their name.

Most [cultures](../Entity.md), except [humans](../Human.md), [don't use](../Entity_token.md#cull-symbol) words from this symbol for their names.

Ribald [poetic forms](../Performer.md#poet) use this symbol in place of the typical [FLOWERY](Flowery.md).

A noun from \[SYMBOL:FOOD\] is expected to be used as the [symbol](../Entity_token.md#select-symbol) for naming a [market](../Market.md), in the form "The \[ADJECTIVE\] \[DOMESTIC\]" or "The \[DOMESTIC\] of \[NOUN\]". The other words are defined by what symbols the [entity](../Entity.md) has assigned to the [OTHER](../Entity_token.md#select-symbol) context (often through REMAINING or ALL).

### SYMBOL:DOMESTIC

This is the **\[SYMBOL:DOMESTIC\]** section of the [language_SYM.txt](../Language_SYM.txt.md) raw file. The file defines categories of words, for use with \[SELECT_SYMBOL\] and \[CULL_SYMBOL\] arguments in the corresponding entity file to create various pool of words available for procedural generation of game content (for example, Dwarf names). See [Language#language_SYM.txt](../Language.md#language-symtxt) and [Entity_token](../Entity_token.md) for more details.

#### Examples

- \[SELECT_SYMBOL:DOMESTIC\]
- \[CULL_SYMBOL:DOMESTIC\]

#### Accented characters

The language files are saved in [code page 437](http://en.wikipedia.org/wiki/Code_page_437) encoding. The accented characters in the language files look like nonsense when interpreted as ASCII or ISO 8859-1, which are often the default. On Windows, viewing the language file with the Terminal font is an easy way to see it correctly.
