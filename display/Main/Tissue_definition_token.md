### Tokens

<table>
<tbody><tr>
<th>Token
</th>
<th>Arguments
</th>
<th>Description
</th></tr>
<tr>
<td> <a href="#tissue-name">TISSUE_NAME</a>
</td>
<td>
<ul><li>name</li>
<li>plural</li></ul>
</td>
<td>plural can alternatively be NP (No Plural) or STP (Standard Plural, adds an 's' on the end).
</td></tr>
<tr>
<td> <a href="#tissue-material">TISSUE_MATERIAL</a>
</td>
<td>
<ul><li><a href="Material_token.md">material token</a></li></ul>
</td>
<td>Defines the tissue material.
</td></tr>
<tr>
<td> <a href="#relative-thickness">RELATIVE_THICKNESS</a>
</td>
<td>
<ul><li>value</li></ul>
</td>
<td>The relative thickness of the tissue. A higher thickness is harder to penetrate, but raising a tissue's relative thickness decreases the thickness of all other tissues.
</td></tr>
<tr>
<td> <a href="#healing-rate">HEALING_RATE</a>
</td>
<td>
<ul><li>value</li></ul>
</td>
<td>Lower is faster. Omitting the token will result in a tissue that never heals.
</td></tr>
<tr>
<td> <a href="#vascular">VASCULAR</a>
</td>
<td>
<ul><li>value</li></ul>
</td>
<td>Related to how much said tissue bleeds. Higher = More bleeding (Which is why the heart has the highest value.)
</td></tr>
<tr>
<td> <a href="#pain-receptors">PAIN_RECEPTORS</a>
</td>
<td>
<ul><li>value</li></ul>
</td>
<td>Related to how much pain your character will suffer when said tissue is damaged. Higher = More pain when damaged (Which is why the bone tissue has a much higher value than other tissues. A broken bone hurts a lot more than a flesh cut.)
</td></tr>
<tr>
<td> <a href="#thickens-on-strength">THICKENS_ON_STRENGTH</a>
</td>
<td>
</td>
<td>The thickness of the tissue increases when character strength increases.
</td></tr>
<tr>
<td> <a href="#thickens-on-energy-storage">THICKENS_ON_ENERGY_STORAGE</a>
</td>
<td>
</td>
<td>Thickness of said tissue increases when the character eats and doesn't exercise sufficiently.
</td></tr>
<tr>
<td> <a href="#arteries">ARTERIES</a>
</td>
<td>
</td>
<td>The tissue contains arteries. Edged attacks have the chance to break an artery, increasing blood loss.
</td></tr>
<tr>
<td> <a href="#scars">SCARS</a>
</td>
<td>
</td>
<td>Simply, whether or not the tissue will be scarred once healed.
</td></tr>
<tr>
<td> <a href="#structural">STRUCTURAL</a>
</td>
<td>
</td>
<td>Holds the body part together. A cut or a fracture disables the body part it's in.
</td></tr>
<tr>
<td> <a href="#connective-tissue-anchor">CONNECTIVE_TISSUE_ANCHOR</a>
</td>
<td>
</td>
<td>Any ligaments or tendons are part of this tissue. Vulnerable to edged attacks, damage disables the limb.
</td></tr>
<tr>
<td> <a href="#settable">SETTABLE</a>
</td>
<td>
</td>
<td>The tissue will not heal, or heals slower, until it is set by a bone doctor.
</td></tr>
<tr>
<td> <a href="#splintable">SPLINTABLE</a>
</td>
<td>
</td>
<td>The broken tissue can be fixed with a cast or a splint to restore function while it heals.
</td></tr>
<tr>
<td> <a href="#functional">FUNCTIONAL</a>
</td>
<td>
</td>
<td>The tissue performs some sort of special function (e.g. sight, hearing, breathing, etc.)  An organ with such a function will stop working if a sufficient amount of damage is sustained by its FUNCTIONAL tissues. If an organ has no FUNCTIONAL tissues, it will stop working only if it is severed or destroyed entirely by heat or cold.
</td></tr>
<tr>
<td> <a href="#nervous">NERVOUS</a>
</td>
<td>
</td>
<td>Nervous function - not used. This token is used in <a href="Body_token.md#nervous">[OBJECT:BODY]</a> tokens.
</td></tr>
<tr>
<td> <a href="#thought">THOUGHT</a>
</td>
<td>
</td>
<td>If a creature has no functioning parts with the THOUGHT token, it will be unable to move or breathe.  NO_THOUGHT_CENTER_FOR_MOVEMENT bypasses this limitation.
</td></tr>
<tr>
<td> <a href="#muscular">MUSCULAR</a>
</td>
<td>
</td>
<td>Seems to affect where sensory or motor nerves are located, and whether damage to this tissue will render a limb useless.
</td></tr>
<tr>
<td> <a href="#smell">SMELL</a>
</td>
<td>
</td>
<td>Used to smell - not used. This token is used in <a href="Body_token.md#smell">[OBJECT:BODY]</a> tokens.
</td></tr>
<tr>
<td> <a href="#hear">HEAR</a>
</td>
<td>
</td>
<td>Used to hearing - not used. This token is used in <a href="Body_token.md#hear">[OBJECT:BODY]</a> tokens.
</td></tr>
<tr>
<td> <a href="#flight">FLIGHT</a>
</td>
<td>
</td>
<td>Unknown - not used. Most likely related to flying, see <a href="Body_token.md#flier">[FLIER] in [OBJECT:BODY]</a>.
</td></tr>
<tr>
<td> <a href="#breathe">BREATHE</a>
</td>
<td>
</td>
<td>Used to breathing - not used. This token is used in <a href="Body_token.md#breathe">[OBJECT:BODY]</a> tokens.
</td></tr>
<tr>
<td> <a href="#sight">SIGHT</a>
</td>
<td>
</td>
<td>Used to seeing - not used. This token is used in <a href="Body_token.md#sight">[OBJECT:BODY]</a> tokens.
</td></tr>
<tr>
<td> <a href="#connects">CONNECTS</a>
</td>
<td>
</td>
<td>Holds body parts together.  A body part will not be severed unless all of its component tissues with the CONNECTS tag are severed.
</td></tr>
<tr>
<td> <a href="#major-arteries">MAJOR_ARTERIES</a>
</td>
<td>
</td>
<td>Causes tissue to sometimes severely bleed when damaged.  This is independent of its VASCULAR value.
</td></tr>
<tr>
<td> <a href="#insulation">INSULATION</a>
</td>
<td>
<ul><li>value</li></ul>
</td>
<td>Tissue supplies the creature with heat insulation. Higher values result in more insulation.
</td></tr>
<tr>
<td> <a href="#cosmetic">COSMETIC</a>
</td>
<td>
</td>
<td>?
</td></tr>
<tr>
<td> <a href="#styleable">STYLEABLE</a>
</td>
<td>
</td>
<td>The tissue can be styled as per a tissue style (defined in an <a href="Entity_token.md">entity</a> entry)
</td></tr>
<tr>
<td> <a href="#tissue-shape">TISSUE_SHAPE</a>
</td>
<td>
<ul><li>value</li></ul>
</td>
<td>Value can be one of the following:
<dl><dt>LAYER</dt>
<dd>Regular layer tissue.</dd>
<dt>STRANDS</dt>
<dd>Can be spun into thread at a farmer's workshop. Edge attacks will pass right through the tissue.</dd>
<dt>FEATHERS</dt>
<dd>Edge attacks will pass right through the tissue.</dd>
<dt>SCALES</dt>
<dd>?</dd>
<dt>CUSTOM</dt>
<dd>?</dd></dl>
</td></tr>
<tr>
<td> <a href="#subordinate-to-tissue">SUBORDINATE_TO_TISSUE</a>
</td>
<td>
<ul><li>value</li></ul>
</td>
<td>Tissue is implicitly attached to another tissue and will fall off if that tissue layer is destroyed. Used for hair and feathers, which are subordinate to skin.
</td></tr>
<tr>
<td> <a href="#tissue-mat-state">TISSUE_MAT_STATE</a>
</td>
<td>
<ul><li>SOLID, SOLID_POWDER, LIQUID, or GAS<br/></li></ul>
<p>(possibly others, as well. Needs testing.)
</p>
</td>
<td>Sets/forces a default material state for the selected tissue.
</td></tr>
<tr>
<td> <a href="#tissue-leaks">TISSUE_LEAKS</a>
</td>
<td>
</td>
<td>The selected tissue leaks out of the creature when the layers above it are pierced.
</td></tr></tbody></table>
