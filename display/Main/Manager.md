The **manager** is a useful [noble](Noble.md) that allows players to create multiple [Work orders](Work_orders~2.md), and also lets them set up profiles for workshops. This means that players can rapidly dispatch any number of jobs from a single screen, without having to add tasks to individual [workshops](Workshop.md).

### Manager skills

The only skill that is relevant for a manager is the [organizer](Organizer.md) skill. There are [soul attributes](Attribute.md#soul-attributes) that affect the skills, and other skills that affect the same attributes' [cross-training](Cross-training.md). The ones relevant for a manager are as follows:

- Analytical ability
- Creativity
- Social awareness

The better match-up with the skill and attributes in the table above, the better manager a dwarf will be.

### Office

A manager only performs their duties in their office, so it's absolutely necessary to assign them one, though they only require a meager office.

To set up a dwarf to be the manager and give them an office:

1. Open the Nobles screen by pressing [![Ui n.png](https://dwarffortresswiki.org/images/7/7b/Ui_n.png)](https://dwarffortresswiki.org/index.php/File:Ui_n.png)n or the crown button on the bottom left toolbar.
2. Select the [![Button appoint position.png](https://dwarffortresswiki.org/images/9/9d/Button_appoint_position.png)](https://dwarffortresswiki.org/index.php/File:Button_appoint_position.png) button next to Manager which will bring up a list of valid candidates in your fort; those with applicable skills will be at the top of the list. Click on the candidate of your choosing; if nobody is particularly suited to the job, picking the Expedition Leader is a reasonable choice. You will see that the Study icon (the chair symbol) for the Manager position is red, meaning their requirement for an office is not met. Exit the Nobles screen.
3. Use the Zones tool [![Ui z.png](https://dwarffortresswiki.org/images/1/13/Ui_z.png)](https://dwarffortresswiki.org/index.php/File:Ui_z.png)z to paint an [![Office medium icon.png](https://dwarffortresswiki.org/images/thumb/b/bb/Office_medium_icon.png/28px-Office_medium_icon.png)](https://dwarffortresswiki.org/index.php/File:Office_medium_icon.png) Office zone in a location and of a size you desire. Once the zone is placed, and while it is still selected, press the [![UI add worker.png](https://dwarffortresswiki.org/images/thumb/9/94/UI_add_worker.png/28px-UI_add_worker.png)](https://dwarffortresswiki.org/index.php/File:UI_add_worker.png) Assign dwarf button and choose the dwarf you've assigned to the Manager position to make this their office.
4. Build a [chair](Chair.md) inside the Office zone you've placed. Other furniture can also be included if you wish to increase the room value, but it must at least have a chair.
5. Once this is done, if you return to the Nobles screen you will see that the Study icon for the Manager position is now green, their need for an office met. You should now be able to queue up work orders.

It is trivially easy for a manager to get experience in the [organizer](Organizer.md) skill. Just queue a lot of jobs to produce 30 of something, such as [Collect Webs](Loom.md), which appears first on the list. The manager will gain experience when validating the order, not when the order is finished. You can cancel the order after it's validated, if you wish.

### Work orders

> *Main article: [Work orders](Work_orders~2.md)*

Work orders are an advanced feature of [Workshop Management](Workshop.md#management) that becomes available with a manager. It allows easier management, automation and/or fine control of the various activities needed to maintain a well-oiled fort. The manager screen lists all work orders in the fortress, shows their status and allows to modify them and place new general orders. It is accessed from the main screen through the [![Ui o.png](https://dwarffortresswiki.org/images/c/c7/Ui_o.png)](https://dwarffortresswiki.org/index.php/File:Ui_o.png)o orders menu, or the clipboard icon in the bottom left of the screen.

Work orders can also be created that apply only to specific workshops, done using the [![Button new work order.png](https://dwarffortresswiki.org/images/d/df/Button_new_work_order.png)](https://dwarffortresswiki.org/index.php/File:Button_new_work_order.png) button on the Work orders tab of the individual workshop's interface. See [Workshop](Workshop.md) for more information.

### Disadvantages

One disadvantage of the work order system is that once your fortress reaches 20 citizens, work orders will not be performed until they are validated by the manager. Work order validation appears to be fairly high priority, but it's best to ensure your manager has ample free time and isn't typically called far from the office for timely order validation.

A second disadvantage is that if there is more than one workshop which can fulfill a particular job set (such as several ordinary [glass furnaces](Glass_furnace.md) dedicated to [sand](Sand.md) collection, plus several [magma glass furnaces](Magma_glass_furnace~2.md) for actual glass production) then the manager will distribute the jobs amongst all those workshops. While this can be an advantage (for example, if you want to speed up the work orders by having multiple workshops), this will make it difficult to dedicate different workshops to different tasks. This can be prevented by entering the interface of specific workshops and moving to the Work orders menu; setting "General work orders allowed" to 0 will prevent the manager from assigning tasks.

### Note

In older versions of *Dwarf Fortress*, options could be set to restrict the allowed tasks at any workshop using Workshop Profiles. This feature needed the manager, but has been removed.
