The **Clothier's shop** is a [workshop](Workshop.md) used by a [Clothier](Clothier.md) to make [clothes](Clothes.md), [ropes](Rope.md) and [bags](Bag.md). It can use [cloth](Cloth.md) made from plant fibers, wool cloth made from [yarn](Yarn.md) or [silk](Silk.md) cloth made from collected spider webs as raw materials. It can also be used to [sew images](Decoration.md) onto [finished goods](Finished_goods~2.md). Cloth and silk must be either bought from [caravans](Trading.md) or [woven](Weaver.md) at a [loom](Loom.md).

The clothier's shop can be built with any building material, and must be built by a [dwarf](Dwarf.md) with the Clothesmaking [labor](Labor.md) enabled.

To create differently sized clothing, request it to be made from the workshop as usual, by adding a new task directly, or through a work order. If you added a task, click on [![Mag glass icon.png](https://dwarffortresswiki.org/images/4/47/Mag_glass_icon.png)](https://dwarffortresswiki.org/index.php/File:Mag_glass_icon.png) icon of the task and select 'Specify size'. Then you can specify the particular race you want to make the clothing item for. Similarly for work orders, you click [![Mag glass icon.png](https://dwarffortresswiki.org/images/4/47/Mag_glass_icon.png)](https://dwarffortresswiki.org/index.php/File:Mag_glass_icon.png) icon of the work order to select the size.

To specify the cloth sub-type of the clothing item, click [![Mag glass icon.png](https://dwarffortresswiki.org/images/4/47/Mag_glass_icon.png)](https://dwarffortresswiki.org/index.php/File:Mag_glass_icon.png) and select 'Specify cloth'.

Note that although cloth/silk backpacks and quivers exist, they cannot be made by the player.

Curiously, the name of this workshop will change if your fortress's primary race provides a custom value for the `[PROFESSION_NAME:CLOTHIER]` token.

### Quirks

Although fabric made from animal products is called "wool cloth," to use wool cloth at the clothier, you must select "make clothes from yarn" in the job menu. This will still use wool cloth, not yarn thread.

The Clothier will ignore cloth in bins, therefore; it is better to make a stockpile of cloth that doesn't permit bins!
