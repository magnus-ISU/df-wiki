<br> **Weapon tokens** define [weapons](Weapon.md). These tokens can only be placed within an ITEM_WEAPON object definition, and most do not function in armor objects.

<td>
<ul><li>maximum ticks</li>

</td>
<td>Determines how long it takes to load ammunition into this weapon. An unskilled ranged weapon user takes the maximum <a href="Time.md">time</a> and a user with legendary skill in that ranged weapon takes the minimum time. Each level in the weapon's ranged skill reduces the loading time proportionally until the minimum time is reached.
<p>LOADED ammo is <a href="Storage.md">stored</a> inside the weapon, while NOCKED ammo stays inside the same inventory and remembers that it is nocked to the weapon.
</p>
</td></tr>

</td>

<ul><li><a href="Skill_token.md">Skill token</a></li></ul>
</td>
<td>The skill to determine effectiveness in melee with this weapon. Defaults to MACE. AXE skill will allow it to be used to chop down trees.  MINING skill will allow it to be used for mining. Outsider adventurers (or regular ones with no points in offensive skills) will receive a weapon with the SPEAR skill, selected at random if multiple ones have been <a href="Modding.md">modded</a> in. All adventurers will also start with a weapon using the DAGGER skill, again selected at random if multiple such weapons exist.
</td></tr>
<tr>

</td>

<tr>

</td>

</td>
<td>Creatures under this size (in cm³, not including <a href="Size.md#creatures">tissue layers</a>) must use the weapon two-handed (or more if the creature has extra [GRASP] parts)<sup>[<a href="https://dwarffortresswiki.org/index.php?title=Talk:Weapon_token&amp;action=edit&amp;redlink=1">Verify</a>]</sup>. Defaults to 50000.  Below this size, one-handed use of a weapon will cause a penalty to hit.
</td></tr>

<tr>
<td> <a href="#attack">ATTACK</a>
</td>
<td>
<ul><li>attacktype:BLUNT or EDGE</li>
<li>contact_area:value</li>
<li>penetration_size:value</li>
<li>verb2nd:string</li>
<li>verb3rd:string</li>
<li>noun:string</li>
<li>velocity_multiplier:value</li></ul>
</td>
<td>You can have many ATTACK tags and one will be randomly selected for each attack, with EDGE attacks 100 times more common than BLUNT attacks. Contact area is usually high for slashing and low for bludgeoning, piercing, and poking. Penetration value tends to be low for slashing and high for stabbing, and is ignored if attack is BLUNT. Verbs are for the 2nd and 3rd person action verbs used to describe the attack. Noun describes what part of the weapon is being used in the attack, or NO_SUB for none. Velocity_multiplier is a multiplier for the <a href="Material_science.md#attack-momentum">attack momentum</a>, increasing effectiveness; stab attacks use 1000 while the lash of a whip uses 5000.  Required.
</td></tr></tbody></table>
