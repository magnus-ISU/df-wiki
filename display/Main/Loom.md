The **Loom** is used to turn [threads](Thread.md) into [cloth](Cloth.md). The command to collect [silk](Silk.md) from [spider webs](Web.md) is also set here.

### Menu

**Loom**

- Collect Webs
  - Non-[silk](Silk.md) threads are created by [plant processing](Plant_processing~2.md) in a [Farmer's workshop](Farmer's_workshop~2.md).
- Weave Cloth (Plant Thread)
- Weave Silk Cloth
- Weave Cloth (Wool/Hair Yarn)
- Weave Metal Cloth

### Common uses

- Turn thread into cloth for use in a [Clothier's shop](Clothier's_shop.md) to make bags, clothes, etc. Every item of thread used produces one item of cloth.

### Notes

- The Loom's functions are automated by default, so any weavers will automatically collect spider webs and weave thread into cloth (if you have any). You can change this behavior in the [![Ui y.png](https://dwarffortresswiki.org/images/c/cb/Ui_y.png)](https://dwarffortresswiki.org/index.php/File:Ui_y.png)y "Labor" menu → "[Standing orders](Standing_orders.md)" tab → "Automated Workshops" tab.
- The automatic re-issuing of jobs takes some time, which can lead to unwelcome pauses when a large quantity of thread is to be woven. Setting the weaving jobs to [![Button repeat.png](https://dwarffortresswiki.org/images/b/b3/Button_repeat.png)](https://dwarffortresswiki.org/index.php/File:Button_repeat.png) repeat tries to keep the current weaver on the job without interruptions.
- One loom only generates one "Collect silk" job, multiple looms let you harvest silk faster if you have enough dwarves with the weaving labor enabled and enough accessible [webs](Web.md).
- There is no task that turns [hair](Hair.md) thread into usable cloth.
- Generally, having automated web collection turned on while the caverns are open can be fatal for unprepared weavers. It is recommended to have this turned off or else some dwarves will be served a heap of !![fun](Fun.md)!!.
