**Tin** is an uncommon, low-value [metal](Metal.md) whose only ore is [cassiterite](Cassiterite.md). Although it is not very useful itself, it is a component in the creation of a number of valuable [alloys](Alloy.md), such as [fine pewter](Fine_pewter.md) (used for decorations and furniture) and [bronze](Bronze.md) (also useful for weapons). On its own, tin is not magma safe, or even fire safe, and will melt in a grass fire.

If you have a lot of cassiterite, it might be better to use it for [tin glaze](Tin_glaze.md) rather than tin bars. Tin bars cannot be used for tin glaze.

<br>

- [Lay pewter](Lay_pewter~2.md) = 2× Tin + [Copper](Copper.md) + [Lead](Lead.md)
- [Fine pewter](Fine_pewter.md) = 3× Tin + [Copper](Copper.md)
- [Trifle pewter](Trifle_pewter~2.md) = 2× Tin + [Copper](Copper.md)
- [Bronze](Bronze.md) = Tin + [Copper](Copper.md)
- [Bismuth bronze](Bismuth_bronze~2.md) = Tin + 2× [Copper](Copper.md) + [Bismuth](Bismuth.md)
