This mod is presumed abandoned, as the developer seems to have vanished off the face of the Earth.

Dwarf Fortress Deserted Squad: HELL UNLEASHED is an expansion on DF: Deserted Squad. The original is currently under development by BW Mods. The mod will include several modifications, such as:

### Telepaths

```
       *Ancient Telepaths are pure-blooded, and can create powerful weapons using their knowledge of nature.
```

Weapons include: Staves, Wands, Books, Dragonswords, and Throwing Darts \[tipped w/ poison\]

```
       *Medieval Telepaths have tainted blood, and lack the knowledge required to manufacture
```

Staves, Wands, Books, and [Dragonswords](https://dwarffortresswiki.org/index.php?title=Dragonswords&action=edit&redlink=1).

```
       *Modern Telepaths are humans with some mental powers. Some call them Psychics. They cannot
```

create or use any weapons of the Ancient Telepaths, and only have three of the Powers--Telekinesis, Telepathy, and Teleportation. Thus, they are weak.

### Basilisks

```
       *Red Basilisks found inside volcanoes
```

```
       *Blue Basilisks found in bodies of water
```

```
       *Cyan Basilisks found everywhere but water and in magma
```

```
       *Green Basilisks found in forests
```

### Dwarves

```
       *Mountain Dwarves life in cities above the ground
```

```
       *Deep Dwarves live in tunnels beneath the earth, and have so adapted.
```

```
       *Forest Dwarves live in forest retreats, much like the elves.
```

### Gods

```
       *Can come down to assist or attack your settlement.
```

<br>

### Wyyvern Guards

```
       Animated statues made of Goldsteel, designed to defend the fortress. Can supplement a Dwarven Military.
```

### Minerals added

```
       Dragonstone used for strengthening weapons
```

```
       Darkstone cannot be used for forging directly, but can be mixed with iron to form Darkmetal,
```

a magic-absorbing substance that can be used to create armor or weapons to be used by those possessing no magic of their own.

```
       Gen, an embodiment of magic itself, can be added to any mineral to create Genmetal, the rarest metal of all.
```

```
       Goldsteel, an alloy of gold, Gen, and Darkstone, can be used to make powerful weapons like Wyyvern Guards
```

<br>

### Additional Info

Deserted Squad will also come with a fortress already settled, with a military and equipment selected to ensure military efficiency.
