### Use

```
name=Tree article link
alt=Alternate label of link
super=superscript next to name (optional)
color=tile color
decid=Yes/No (not included=No)
biome=Biome Name (see Biome tokens)
biome2=,biome3=,biome4=,...,biome9= (for multiple biomes)
dry=wet/dry (y=dry, n=wet, b=both, not included=none)
align=Good/Evil/Savage (not included if All)
tile1={{tile||0:0}} tree part (if this is not included, it will display the default tree parts as shown above)
tile2=,tile3=,tile4,...,tile9=
dense=wood density
drink=Tree fruit alcohol (optional)
drinkv=drink value×5 (optional)
eat=eat raw (y=yes, not included=no)
cook=eat cooked (y=yes, p=processed, not included=no)
grow1={{tile||0:0:0}} growth 1
grow2=,grow3,grow4,...grow9=
graphic=trunk graphic
sapling=sapling graphic
```
