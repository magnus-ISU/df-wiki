### Usage

Defining a citation:

```
{{cite|name|source}}
```

("source" can be either a page name or an external URL)

Reusing a citation:

```
{{cite|name}}
```

Citations can be redefined, but doing so will increase their ID (shown in superscript). Definitions only apply to citations that follow them.
