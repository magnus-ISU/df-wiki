# Template:Nsv/doc

*[Source](https://dwarffortresswiki.org/index.php/Template:Nsv/doc) &middot; revision 236347 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../mirror/wikitext/Template/Nsv/doc.wiki)*

---
{{[nsv](../Nsv.md)}} is the inverse of {{[ns](../Ns.md)}}—it takes a namespace and returns the corresponding version.

### Usage

```
{{nsv|1|release=|title=}}
```

#### Parameters

- `1` — Namespace (`DF2014`, `v0.34`, `DF2012`, `v0.31`, `DF2010`, `40d`, `23a`). Putting a nonexistent namespace in the first parameter or leaving it in blank will result in this error message: 53.16. If the parameter is not included at all, it returns the most recent version of the game instead.
- `title` — Displays a leading "v" or "DF " in front of the version number. Case insensitive.
  - "v" — Accepts `version`, `ver`, or `v`.
  - "DF " — Accepts `dwarf fortress`, `dwarffortress`, or `df`.

#### Examples

```
* {{nsv|DF2012}}
* {{nsv|v0.31}}
* {{nsv|40d|title=Dwarf Fortress}}
* {{nsv|23a|title=v}}
* {{nsv}} (equivalent to {{Current/version}})
```

- 0.34.11
- 0.31.25
- DF 0.28.121.40d
- v0.23.130.23a
- Error: Namespace not found (equivalent to 53.16)
