{{[Tl](../Tl.md)}} is a simple macro template used to display a template name as a displayed formatted template, with the template linked inside: **tl** stands for **t**emplate **l**ink. It is meant to be used on internal pages and template documentation to exposit simple templates with up to three variables supported.

`{{tl|cv}}` → {{[cv](../Cv.md)}}<br> `{{tl|dffd|997}}` → {{[dffd](../Dffd~2.md)|997}}<br> `{{tl|dffd|997|Map Compressor}}` → {{[dffd](../Dffd~2.md)|997|Map Compressor}}<br> `{{tl|tt|{{tt|[HOMEOTHERM]}}|Warm-blooded creature|#4a8}}` → {{[tt](../Tt.md)|`[HOMEOTHERM]`|Warm-blooded creature|#4a8}}
