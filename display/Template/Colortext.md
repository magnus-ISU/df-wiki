This template is used for creating colored text without the need to use CSS "span" or "div" tags.

### Syntax

The syntax of this template must be typed like this:<br> `{{colortext|COLOR|Displayed Text}}`<br><br>

There are two ways to apply color: either by using a color name that is recognized by the HTML in a browser (such as "red", "lime" or "darkgrey"), or by using a hex code such as "#550000" (which is dark red) or "#0000ff" (which is blue). Note that adding another two numbers will have those numbers control the opacity of the text.<br><br> Typing the following: `{{colortext|#ff0080|This is very noticable fushia text.}}`<br> Will produce this: This is very noticable fushia text.<br><br> Note that text can be formatted within the template: `{{colortext|#0072ED|'''''This navy blue text has both bolds and italics.'''''}}`<br> Which produces this: ***This navy blue text has both bolds and italics.***
