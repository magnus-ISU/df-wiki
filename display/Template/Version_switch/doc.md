# Template:Version switch/doc

*[Source](https://dwarffortresswiki.org/index.php/Template:Version_switch/doc) &middot; revision 280237 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../mirror/wikitext/Template/Version_switch/doc.wiki)*

---
This template includes other templates based on the current page's namespace.

### Usage

```
{{version switch|Base template name}}
```

### Examples

```
{{version switch|metals}}
```

- When the template is included in the template namespace, a list of supported templates will be displayed (such as [Template:DF2014 metals](../DF2014_metals.md), [Template:v0.34 metals](../V0.34_metals.md), etc.).
- When included from a supported namespace, the appropriate template for that namespace will be included (such as [Template:40d metals](../40d_metals.md) when included on a 40d page).
- When included in any other namespace, the template for the current version will be included ([Template:v50 metals](../V50_metals.md) in this case).
