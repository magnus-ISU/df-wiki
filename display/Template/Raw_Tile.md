# Template:Raw Tile

*[Source](https://dwarffortresswiki.org/index.php/Template:Raw_Tile) &middot; revision 284197 &middot; retrieved 2026-09-13 &middot; [wikitext](../../mirror/wikitext/Template/Raw_Tile.wiki)*

---
{{{1}}}

**Template:Raw Tile** can be used to display tiles close to what they appear as in Dwarf Fortress. It is designed to be used in grids. There is a [variant with padding](Tile.md) for free-standing use. The [Dwarf template](Dwarf.md) can be used to insert dwarf faces.

### Usage

- {{Raw Tile|\<character\>|a:b:c}}
  - where "a:b:c" is a [COLOR token](../Main/Color.md) value specifying both foreground and background color
- {{Raw Tile|\<character\>|a:b}}
  - where "a:b" is a COLOR token value specifying foreground color only; background will be defaulted to black
- {{Raw Tile|\<character\>|#xxx|#yyy}}
  - where #xxx is the foreground color and #yyy is the (optional, default black) background color

#### Special characters

Special characters can be copied from the [character table](../Main/Character_table~2.md). Characters used in the template syntax (e.g. | or =) need to be escaped (| can be written `{{!}}`, = can be written `{{=}}`).

#### Examples

|  |  |  |  |  |  |
| --- | --- | --- | --- | --- | --- |
| ═ | ═ | ┼ | ┼ | ═ | ═ |
| ÷ | = | ÷ | ÷ | ÷ | ÷ |
| ÷ | ÷ | ÷ | ÷ | ÷ | ÷ |
| ÷ | ÷ | ÷ | = | ÷ | = |

...can be made with:
