This is like [Template:Version](../Version.md) except for whole articles or sections.<br> The use for which it was created was for articles copypasted from the old wiki.

Articles that include this template are automatically added to [Category:Needs update](../../Category/Needs_update.md).

More details can be included in a named parameter:

```
{{old|Details here}}
```
