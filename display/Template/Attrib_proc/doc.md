---
<br> Usage:

```
{{attrib_proc|creature raws}}
```

Returns a formatted list of "interesting" attribute tags for the given raw creature data.

After making any edits that change the way categorization works in this template, you must also make a [null edit](http://en.wikipedia.org/wiki/Help:Purge#Null_edit) to {{[Creaturelookup/0](../Creaturelookup/0.md)}} and {{[40d creaturelookup/aux](../40d_creaturelookup/%25aux.md)}} in order to propagate the changes correctly.
