### Usage

Input value -\> a (default 50)<br> Max value -\> b (default 100)<br> Filled square color -\> y (default #ff5)<br> Half-filled square color -\> z (default #dd0)<br> Other parameters include advStyle (default empty), height (default 6) and stretch (default 35).<br>

```
 {{PVm|a|b|y|z}}
```
