# Template:Random image

*[Source](https://dwarffortresswiki.org/index.php/Template:Random_image) &middot; revision 249878 &middot; retrieved 2026-09-13 &middot; [wikitext](../../mirror/wikitext/Template/Random_image.wiki)*

---
This template returns a random image from a gallery subpage (by default "/gallery"). To add an image to the rotation, edit the appropriate gallery subpage, not this page.

<br> Usage:

> {{random image}}

Adds a random image from "/gallery", size 140x200px.

<br>

> {{random image | dragonpics | size=400x400px | location=right | link=dragon }}

Adds a random image from "dragonpics", size 400x400px, aligned on the right, and link it to "dragon".
