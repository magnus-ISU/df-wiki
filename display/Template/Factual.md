### Documentation

Simply use {{factual|any factual information here}}. This template can take extended formatting.

### Example

```

* You can use wiki markup just fine in this template.
* Including bullets, '''bold''' text, ''italic'' text, and other things.
* Links are the same, [[cv:dwarf|dwarfiness]] for example.
# Oh man, we need a numbered list now.
#* With a sub list.
```
