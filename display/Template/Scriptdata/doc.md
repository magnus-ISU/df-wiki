# Template:Scriptdata/doc

*[Source](https://dwarffortresswiki.org/index.php/Template:Scriptdata/doc) &middot; revision 307865 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../mirror/wikitext/Template/Scriptdata/doc.wiki)*

Displays [scripts](../../Category/Lua_script_pages.md) from the *Page name/script* directory.

Derived from [Template:Gamedata](../Gamedata.md), with a few changes specific to displaying syntax highlighting.

Can be given a custom script to display instead:

- `|script=` defines the content of the custom entry.

- `|title=` parameter functions in the same way [Template:Gamedata](../Gamedata.md) does so.

- Automatically applies `<syntaxhighlight lang="lua">` to entries.

<br> Example of a custom script that uses all parameters:

```
{{Scriptdata
|title=Identity language
|script=
languages.GEN_IDENTITY=function()
    -- just to demonstrate the absolute most basic method of generating one of these
    -- also so that you can just mod stuff to use GEN_IDENTITY
    local tbl={}
    local unempty = function(str1, str2) 
        return str1=='' and str2 or str1
    end
    for k,v in ipairs(world.language.word) do
        local str=''
        str=unempty(str,v.NOUN_SING)
        str=unempty(str,v.ADJ)
        str=unempty(str,v.VERB_FIRST_PRES)
        str=unempty(str,string.lower(v.token))
        tbl[v.token]=str
    end
    return tbl
end
}}
```
