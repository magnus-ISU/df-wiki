This is a template for color schemes, designed for [color scheme](../Main/Color_scheme.md).

#### Notes

- This uses "gray", not "grey"
- Colors can be defined in any order

#### Example

```
{{color scheme
|red=f00
|green=090
|blue=00f
|white=fff
|black=000
|brown=990
|yellow=ff0
|magenta=f0f
|cyan=0ff
|lcyan=6ff
|lred=f66
|lgreen=6f6
|lblue=66f
|lmagenta=f6f
|dgray=666
|lgray=bbb
}}
```
