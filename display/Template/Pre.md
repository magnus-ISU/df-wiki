This template lets you use

```
this style
```

with wiki markup and has other cool features take more work without a template.

### Features

- You can include up to 19 vertical bars (`|`) **without** using the {{!}} template. If you feel like it you can add more (if you know how), but they might be deleted if a new version is copied over.
- Overflowing text wraps!

### Examples

```
{{pre|'''Bold text''' ''Italics'' <s>strikethrough</s>}}
```

`Bold text Italics strikethrough`

```
{{pre|'''{{tc|#f0f|Bold, magenta text}}''' is useful for getting someone's attention.}}
```
