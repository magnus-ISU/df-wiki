Marks an incorrectly-namespaced page for deletion.

Note that pages in an incorrect namespace should ideally be moved to the **correct** namespace before the original is tagged for deletion.

Usage:

```
{{wrong namespace}}
```

or:

```
{{wrong namespace|correct namespace}}
```
