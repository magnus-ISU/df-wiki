### ([view](Ct/doc.md) - [edit](https://dwarffortresswiki.org/index.php?title=Template:Ct/doc&action=edit) - [history](https://dwarffortresswiki.org/index.php?title=Template:Ct/doc&action=history) - [purge](https://dwarffortresswiki.org/index.php?title=Template:Ct&action=purge)) Documentation

This template assists in the display of [temperatures](../Main/Temperature.md), measured in degrees Urist, by adding a hovertext which displays the temperature in degrees Celsius, rounded to the nearest one decimal point. It is actually quite flexible, being capable of parsing the number it needs out of entire lines of text, but it is stylistically recommended you restrict the template to the temperature itself:

| Code | Product |
| --- | --- |
| `[[Water]] freezes at {{ct\|10000}}.` | [Water](../Main/Water.md) freezes at 10000 °U. |
| `{{ct\|[[Water]] freezes at 10000 °U.}}` | [Water](../Main/Water.md) freezes at 10000 °U. |
| `The temperature of [[magma]] is {{ct\|12000}}.` | The temperature of [magma](../Main/Magma.md) is 12000 °U. |

The template can parse both numbers and NONE, the two temperature-related values most commonly used in the raws. You can give it a second argument (which defaults to "none") for a fallback if and only if the value given is precisely NONE. This is helpful for templates that use data directly derived from parsing [raw files](../Main/Raw_file.md).

| Code | Product |
| --- | --- |
| `The ignition point of [[slate]]: {{ct\|NONE}}.` | The ignition point of [slate](../Main/Slate.md): none. |
| `The ignition point of [[slate]] is {{ct\|NONE\|nonexistent; it never ignites}}.` | The ignition point of [slate](../Main/Slate.md) is nonexistent; it never ignites. |
