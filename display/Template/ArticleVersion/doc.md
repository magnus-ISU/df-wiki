This template is to be used on all pages that are game version specific.

#### Usage

To use this template simply add {{[av](../Av.md)}} to the top of an article.

#### "There's a new version! What do I do?"

If the [version](../../Main/Version.md) is major enough to warrant a new namespace (this will have been determined by the community), then the most important thing to do is update [this page](../../Dwarf_Fortress_Wiki/Current.md) with the newest namespace. This will cause all the templates to show the proper current/outdated message.

The second thing to do is update the [ArticleVersion template](../ArticleVersion.md). This template is widely used and quite complicated; please do not attempt to modify it unless you are very familiar with wiki template code. Instead, please post an update request on its [talk page](https://dwarffortresswiki.org/index.php/Template_talk:ArticleVersion).

A list of templates that need to be updated in each major version can be found [here](../../Dwarf_Fortress_Wiki/Major_version_checklist.md).
