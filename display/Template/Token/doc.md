### Examples

```
*{{token|ATTACK|am}}
*{{token|ARMORLEVEL|ar}}
*{{token|SPEED|c}}
*{{token|MANNERISM_EYES}}
*{{token|NAME|c|cat:cats:cat}}
*{{token|}}
```

- `[ATTACK]` (ammo)
- `[ARMORLEVEL]` (armor)
- `[SPEED]` (creature)
- `[MANNERISM_EYES]` (token type not defined, guesses mannerism)
- `[NAME:cat:cats:cat]`
- `[]`
