# Template:RT

*[Source](https://dwarffortresswiki.org/index.php/Template:RT) &middot; revision 244938 &middot; retrieved 2026-09-13 &middot; [wikitext](../../mirror/wikitext/Template/RT.wiki)*

**Template:RT** is a version of Template:Raw Tile with the cell padding parameter incorporated to minimize the number of bytes it uses. See [Template:Raw Tile](Raw_Tile.md) for further usage notes.

[Template:RT0](RT0.md) is the same template with a black background color hard-coded.

[Template:RTC](RTC.md) is the same template with a black background color and a gray foreground color hard-coded.

[Template:RTF](RTF.md) is the same template with a black background color and a white foreground color hard-coded.

[Template:RTB](RTB.md) is a blank tile of any color.

[Template:000](000.md) is a blank black tile.

[Template:CCC](CCC.md) is a blank grey tile, used for grey stone walls.

[Template:FFF](FFF.md) is a blank white tile, used for light stone walls.

[Template:888](888.md) is a blank dark grey tile, used for dark stone walls.

[Template:C.C](C.C.md) is a grey cavern floor tile, used for plain cavern floors.

[Template:H2O](H2O.md) is a blue ≈ on a black background, used for water tiles.

[Template:RTS](RTS.md) is a teal ▓ on a black background, used for sky tiles.

[Template:RTL](RTL.md) is a template for maximized flexibility and features.

### Usage

```
{{RT|<character>|<color>|<background>}}
{{RT0|<character>|<color>}}
{{RTC|<character>}}
{{RTB|<color>}}
{{000}}, {{888}}, {{CCC}}, {{FFF}}, {{C.C}}
{{RTL|<character-color>|<character>|<background-color>|<superior>|<superior-color>|<superior-align>}}
```
