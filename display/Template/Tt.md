Teletype (\<tt\>) is stylistically recommended for usage when referring to [tokens](../Main/Token.md), inline pieces of code, file formats, et cetera, to easily distinguish between regular wiki text and references to the game's code. This template makes the process slightly easier. It takes up to three parameters: the tagged contents, required for anything to display; the second adds mouseover text, which is completely optional and rarely needed; and the third allows you to change the color of the mouseover underline - #00C is the default - and so is all the more optional.
