This template is intended for use when the accuracy of a statement is in doubt or is being questioned by an editor. It is an open request for confirmation or refutation, and/or more research, and any appropriate editing to bring the statement toward a more acceptable phrasing.

The template will automatically place tagged articles into [Category:Verify](../Category/Verify.md).

### Usage

When using this template, it is strongly suggested to raise the issue on the talk page elaborating exactly what needs to be verified.

> `Example.{{verify}}`

Clicking on the link directs to the **talk page** of the page that the {{verify}} was added to, where any discussion of the question should be raised and conducted. If there is no current Discussion page, the link will be **red**, appearing like this: <sup>[Verify](https://dwarffortresswiki.org/index.php?title=This_is_an_example_of_an_article_with_no_%22Talk%22_page._(Please_do_NOT_create_this_page,_thanks.)&action=edit&redlink=1)</sup>.

### Parameters

- `|Reason=` or `|1=` for adding a quick note about what to verify. For example:

> `Example.{{verify|the value is still relevant for current ver}}`
> `Example.{{verify|Reason=the value is still relevant for current ver}}`
