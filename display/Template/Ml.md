# Template:Ml

*[Source](https://dwarffortresswiki.org/index.php/Template:Ml) &middot; revision 182531 &middot; retrieved 2026-09-13 &middot; [wikitext](../../mirror/wikitext/Template/Ml.wiki)*

---
Simple template for linking to mainspace from an article in a versioned namespace, particularly for redirects only existing in the mainspace. For example, [kitten](../Main/Kitten.md) (`[[kitten]]`) works here, but not in a DF2012 article - you need to use [kitten](../Main/Kitten.md) (`[[Main:kitten|kitten]]`).

Usage: Similar to using double-bracket syntax (2 parameters, link title is the first parameter if the second is left blank).

```
{{ml|kitten}}
```

[kitten](../Main/Kitten.md)

```
{{ml|kitten|this page}}
```

[this page](../Main/Kitten.md)

**Note:** `subst`ing this template will work, and is probably helpful in some cases (see {{[unsigned](Unsigned.md)}})
