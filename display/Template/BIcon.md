### ([view](BIcon/doc.md) - [edit](https://dwarffortresswiki.org/index.php?title=Template:BIcon/doc&action=edit) - [history](https://dwarffortresswiki.org/index.php?title=Template:BIcon/doc&action=history) - [purge](https://dwarffortresswiki.org/index.php?title=Template:BIcon&action=purge)) Documentation

This is a template used to display biome icons. You can hover over the icon with the mouse for the name of the biome it represents.

Usage:

```
{{bIcon|<ID# OR Token>}}
```

Examples:

- {{BIcon|12}} -\> [`╞`](../Main/Biome.md)
- {{BIcon|RIVER_TROPICAL_BRACKISHWATER}} -\> [`~``B`](../Main/Biome.md)
- {{BIcon|ALL_MAIN}} {{BIcon|ANY_LAND}} {{BIcon|ANY_OCEAN}} -\> [ALL](../Main/Biome.md) [ALL](../Main/Biome.md) [ALL](../Main/Biome.md)

**NOTES:**

- For cavern layer depth indicators use 'C1', 'C2', 'C3' and 'TO'. ex: [`1`](../Main/Biome.md) [`2`](../Main/Biome.md)[`-`](../Main/Biome.md)[`3`](../Main/Biome.md)
- There are ID#'s included for individually specifying saltwater, freshwater, and brackish-water. They are 'S', 'F' and 'B' respectively.
- For night creatures and hidden fun stuff use 'N' and 'HFS'; [`☽`](../Main/Night_creature.md) [`☿`](../Main/Hell.md)

<br> To see a full listing of which ID#s and tokens correspond to which biome, see [this article](../Main/Biome_token.md).
