### ([view](Deletion/doc.md) - [edit](https://dwarffortresswiki.org/index.php?title=Template:Deletion/doc&action=edit) - [history](https://dwarffortresswiki.org/index.php?title=Template:Deletion/doc&action=history) - [purge](https://dwarffortresswiki.org/index.php?title=Template:Deletion&action=purge)) Documentation

Add {{deletion}} or {{[del](Del.md)}} to the top of a page to mark it for deletion. The template will display a warning and add the page to [Category:Deletion](../Category/Deletion.md) for an admin to review.

Adding a pipe (`|`) after either command will change the default text to appear instead as the editor's "reasoning" for the deletion.<br> There is no need to type a period at the end of the reasoning, as a period is already provided in the template.

For example, `{{del|This is a sample deletion request}}` will appear as...
