# Template:Documentation subpage/doc

*[Source](https://dwarffortresswiki.org/index.php/Template:Documentation_subpage/doc) &middot; revision 288021 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../mirror/wikitext/Template/Documentation_subpage/doc.wiki)*

> *Not to be confused with [Template:Documentation](../Documentation.md).*

This template displays a message that the current page is a documentation subpage.

### Usage

{{Documentation subpage}} or {{Documentation subpage|\[\[Page where the documentation transcluded\]\]}}

<br><br>

#### Text customization

The parameters `|text1=` and `|text2=` can be used to set the text of, respectively, the template's first and second lines. #### Other parameters

`|inhibit=yes` will prevent this template from generating any categories. (By default, "*Namespace* documentation pages" (usually [Category:Template documentation pages](../../Category/Template_documentation_pages.md)) is added, or [Category:Documentation subpages without corresponding pages](https://dwarffortresswiki.org/index.php?title=Category:Documentation_subpages_without_corresponding_pages&action=edit&redlink=1) if the main page doesn't exist.)

### Display

This template should normally be placed at the top of /doc pages. It changes output depending on where it is viewed:

- On a /doc page, it displays a box explaining template documentation and links to the template page.
- On other pages – i.e. pages transcluding the /doc page – the template will not show. The template page itself (which contains `Template:Template link`) will automatically note that the documentation is [transcluded](https://dwarffortresswiki.org/index.php?title=Help:Transclusion&action=edit&redlink=1) from a subpage.

### Functions

In addition to its message, the template adds pages to [Category:Template documentation pages](../../Category/Template_documentation_pages.md), [Category:User documentation pages](https://dwarffortresswiki.org/index.php?title=Category:User_documentation_pages&action=edit&redlink=1), or similar (named after the subject space), but only for documentation pages in namespaces with the subpage feature. It defaults the [sort key](https://dwarffortresswiki.org/index.php?title=M:Help:Categories&action=edit&redlink=1) to the page name without namespace: Template:Foo, for example, would be sorted as "Foo", i.e. under "F".
