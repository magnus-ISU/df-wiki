This template extracts the minimum and/or maximum egg clutch size from a creature's raws.

Usage:

```
{{creature/eggs/0|Creature|n}}
```

"Creature" defaults to the page name.

"n" can be used to specify the first or second number. If any value other than "1" or "2" is passed, both values are returned, separated by ":"
