# Template:Deletion/doc

*[Source](https://dwarffortresswiki.org/index.php/Template:Deletion/doc) &middot; revision 279675 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../mirror/wikitext/Template/Deletion/doc.wiki)*

---
Add {{[deletion](../Deletion.md)}} or {{[del](../Del.md)}} to the top of a page to mark it for deletion. The template will display a warning and add the page to [Category:Deletion](../../Category/Deletion.md) for an admin to review.

Adding a pipe (`|`) after either command will change the default text to appear instead as the editor's "reasoning" for the deletion.<br> There is no need to type a period at the end of the reasoning, as a period is already provided in the template.

For example, `{{del|This is a sample deletion request}}` will appear as...
