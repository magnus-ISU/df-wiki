This template consists of `<div style="clear:both;"></div>`

{{clear}} makes the following content start below all previous content in all columns. It can be used to stop text from flowing next to unrelated images or sidebars.

In addition, the first parameter can be used to override "both"; for example, {{clear|left}} will force the following content to appear below floating content on the left side only. (See [this page](http://www.w3schools.com/cssref/pr_class_clear.asp) for more information.)

### Use on creature pages

This template can often prevent misaligned raw and creature boxes caused by the sidebar at the left of creature pages.
