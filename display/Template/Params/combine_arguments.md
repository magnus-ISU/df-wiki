# Template:Params/combine arguments

### ([view](combine_arguments/doc.md) - [edit](https://dwarffortresswiki.org/index.php?title=Template:Params/combine_arguments/doc&action=edit) - [history](https://dwarffortresswiki.org/index.php?title=Template:Params/combine_arguments/doc&action=history) - [purge](https://dwarffortresswiki.org/index.php?title=Template:Params/combine_arguments&action=purge)) Documentation

Use to create a template that combines {{{1}}} to {{{100}}} into one parameter, ignoring the pipes separating the arguments.

### Examples

**Page: Template:Foo**

```
Foo: ''{{subst:Params/combine arguments}}''
```

After saving, becomes:

```
Foo: ''{{{1|}}}{{{2|}}}{{{3|}}}...{{{100|}}}''
```
