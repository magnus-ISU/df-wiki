# Template:Params/combine arguments/doc

*[Source](https://dwarffortresswiki.org/index.php/Template:Params/combine_arguments/doc) &middot; revision 192339 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../../mirror/wikitext/Template/Params/combine_arguments/doc.wiki)*

---
Use to create a template that combines {{{1}}} to {{{100}}} into one parameter, ignoring the pipes separating the arguments.

### Examples

**Page: Template:Foo**

```
Foo: ''{{subst:Params/combine arguments}}''
```

After saving, becomes:

```
Foo: ''{{{1|}}}{{{2|}}}{{{3|}}}...{{{100|}}}''
```
