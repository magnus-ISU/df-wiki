# Template:Dwarf/doc

*[Source](https://dwarffortresswiki.org/index.php/Template:Dwarf/doc) &middot; revision 306916 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../mirror/wikitext/Template/Dwarf/doc.wiki)*

![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png)

**Template:Dwarf** can be used to display dwarves close to what they appear as in Dwarf Fortress. It can be used together with the [raw tile template](../Raw_Tile.md), however it doesn't scale with the user's font size. This might lead to problems for users with uncommon settings.

### Usage

```
{{Dwarf|1|2|3|type=}}
```

#### Parameters

- `1` – Sets the [color](../../Main/Color.md#color-values) (`#:#`).
- `2` – Sets the size. Defaults to `10px`.
- `3` – Mouseover/Tooltip.
- `type` – Sets the symbol to civilian ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) or military ![](https://dwarffortresswiki.org/images/c/cf/Dwarf2.png). Defaults to civilian icon if the parameter is not defined.
  - ![](https://dwarffortresswiki.org/images/e/ed/Dwarf.png) – Accepts `civilian`, `civ`, `c`, or `1`.
  - ![](https://dwarffortresswiki.org/images/c/cf/Dwarf2.png) – Accepts `military`, `mil`, `m`, or `2`.
  - ![](https://dwarffortresswiki.org/images/4/42/Dwarf3.png) – Accepts `adventurer`, `merchant`, `diplomat`, `adv`,`merch`, `dip`, `a`, or `3`.
