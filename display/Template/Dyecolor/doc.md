#### Description

A very simplistic and small template that shows in-game dye colors in a small box.

#### Usage

{{dyecolor|HTML color name OR hex value}}<br> For example, {{dyecolor|green}} will output the following...<br> **Note:** If using a hex color value, the # symbol *must* be included.
