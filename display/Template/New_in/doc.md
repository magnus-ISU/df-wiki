# Template:New in/doc

*[Source](https://dwarffortresswiki.org/index.php/Template:New_in/doc) &middot; revision 293953 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../mirror/wikitext/Template/New_in/doc.wiki)*

---
The {{[New in](../New_in.md)}} message box is put at the top of articles that contain information only relevant to recently released [versions](../../Main/Version.md) of *Dwarf Fortress*. It notifies readers that certain features, mechanics, and elements of the game mentioned in the article are applicable to the version and after, but not versions prior to. The message box also specifies whether or not older saves from previous versions are still [compatible](../../Main/Save_compatibility.md) in the version.

### Usage

```
{{New in|1|2}}
```

#### Parameters

- `1` – Version number.
- `2` – Overrides the word "page" (optional).

#### Examples

```
{{New in|53.16}}
{{New in|0.47.05}}
{{New in|0.44.01}}
{{New in|0.43.01|article}}
{{New in|0.42.01|section}}
{{New in|0.40.03|category}}
{{New in|0.34.01|template}}
```
