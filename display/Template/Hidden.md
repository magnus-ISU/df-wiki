# Template:Hidden

*[Source](https://dwarffortresswiki.org/index.php/Template:Hidden) &middot; revision 183232 &middot; retrieved 2026-09-13 &middot; [wikitext](../../mirror/wikitext/Template/Hidden.wiki)*

Huge thanks to everyone over there who helped make this possible. <br> **None of the below text is my own. It is more a place holder now than anything.. Change at will! :)** <br> <br> This template creates a [dynamic navigation box](http://en.wikipedia.org/wiki/NavFrame) using style sheet declarations in [MediaWiki:Common.css](https://dwarffortresswiki.org/index.php/MediaWiki:Common.css) and Javascript code in [MediaWiki:Common.js](https://dwarffortresswiki.org/index.php/MediaWiki:Common.js). It displays the first parameter (the heading) with a \[show\] link on the right. If \[show\] is clicked by the user, the second parameter (the body) is displayed below the heading and the \[show\] link becomes \[hide\]. Clicking on \[hide\] then hides the body again and the \[hide\] link becomes \[show\] again.

The template does **not** provide an argument to designate the initial state of the show/hide control. In the nested case, show/hide controls in hidden content retain their state. There is no facility for *collapse all* or *reveal all*.

### Usage

#### Syntax

```
{{Hidden
|header=
|content=
|style=
|headerstyle=
|contentstyle=
|fw1=
|fw2=
|bg1=
|bg2=
|ta1=
|ta2=
}}
```

#### Parameters

Only two parameters are required for this template:

**header**
> text for header (or title); alternative to using unnamed parameter {{{1}}}
**content**
> text for content (or body); alternative to using unnamed parameter {{{2}}}

##### Optional

**style**
> add [CSS](https://dwarffortresswiki.org/index.php?title=W:Cascading_Style_Sheets&action=edit&redlink=1) to the main div.
**headerstyle**
> add [CSS](https://dwarffortresswiki.org/index.php?title=W:Cascading_Style_Sheets&action=edit&redlink=1) to the header.
**contentstyle**
> add [CSS](https://dwarffortresswiki.org/index.php?title=W:Cascading_Style_Sheets&action=edit&redlink=1) to the content box.
**expanded**
> any nonblank value will cause the template to be initially expanded by default.

**Note:** This template will not respect the user preference "justify paragraphs".
