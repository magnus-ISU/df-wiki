# Template:Colorlinks

### ([view](Colorlinks/doc.md) - [edit](https://dwarffortresswiki.org/index.php?title=Template:Colorlinks/doc&action=edit) - [history](https://dwarffortresswiki.org/index.php?title=Template:Colorlinks/doc&action=history) - [purge](https://dwarffortresswiki.org/index.php?title=Template:Colorlinks&action=purge)) Documentation

This template changes the color of all links in **{{{2}}}** to **{{{1}}}**.

### Examples

```
{{colorlinks|red|[[DF2012:Cat]]}}
```

[DF2012:Cat](https://dwarffortresswiki.org/index.php/v0.34:Cat)

```
{{colorlinks|blue|[[Main Page|Link to Main Page]]}}
```

[Link to Main Page](../Main/Main_Page.md)

Suffixes are colored too:

```
{{colorlinks|#f60|[[Cat]]s are in [[DF2012:cat|v0.34]] and [[23a:cat|the 23a version]]}}
```

[Cats](../Main/Cat.md) are in [v0.34](https://dwarffortresswiki.org/index.php/v0.34:Cat) and [the 23a version](https://dwarffortresswiki.org/index.php/23a:Cat)
