# Template:Magmasafe/test

*[Source](https://dwarffortresswiki.org/index.php/Template:Magmasafe/test) &middot; revision 279352 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../mirror/wikitext/Template/Magmasafe/test.wiki)*

---
Returns either yes or no based on if the input temperature (either a number value or NONE) is safe to dump in magma.

For example:

`{{Magmasafe/test|10000}}` → `no`

`{{Magmasafe/test|12000}}` → `no`

`{{Magmasafe/test|14000}}` → `yes`

`{{Magmasafe/test|NONE}}` → `yes`
