# Template:Code

*[Source](https://dwarffortresswiki.org/index.php/Template:Code) &middot; revision 261584 &middot; retrieved 2026-09-13 &middot; [wikitext](../../mirror/wikitext/Template/Code.wiki)*

Wrapper template that show syntax-highlighted text. The template uses the `<syntaxhighlight>` tag (see [Extension:SyntaxHighlight](https://www.mediawiki.org/wiki/Extension:SyntaxHighlight)).

### Usage

Simply wrapper the template around your code: {{code|\<your code here\>}} or {{code|code=\<your code here\>}}

```
{{{code|
...
Your code
...
}}
```

Note: If the content includes an equals sign (=), you must specify the parameter explicitly:

```
{{{code|code=
...
Your code with = sign
...
}}
```
