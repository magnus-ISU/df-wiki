<sup>[Bug](#bugs)</sup>### ([view](Bug/doc.md) - [edit](https://dwarffortresswiki.org/index.php?title=Template:Bug/doc&action=edit) - [history](https://dwarffortresswiki.org/index.php?title=Template:Bug/doc&action=history) - [purge](https://dwarffortresswiki.org/index.php?title=Template:Bug&action=purge)) Documentation Used for linking to bugs on the [Bug Tracker](https://dwarffortressbugtracker.com/) See also [Category:References to fixed bugs](../Category/References_to_fixed_bugs.md) ### Usage The first parameter is the number of the bug on the bug tracker. Leading 0's aren't necessary. ```
{{bug|296}}
``` <sup>[Bug](#bugs):[296](https://dwarffortressbugtracker.com/view.php?id=296)</sup> An optional parameter is a link to the workaround. This should be used temporarily, while the bug is **not** fixed. If the bug is fixed, remove it from the article. ([Rule T](../Dwarf_Fortress_Wiki/Community_Portal.md#t)) Note that this parameter is **named**. You need to use `workaround=http://...`, not just the link as the second parameter. ```
{{bug|6290|workaround=http://www.bay12forums.com/smf/index.php?topic=122782.0}}
``` <sup>[Bug](#bugs):[6290](https://dwarffortressbugtracker.com/view.php?id=6290) ([Workaround](http://www.bay12forums.com/smf/index.php?topic=122782.0))</sup> If the workaround is listed in the comments of the bug report, use ```
{{bug|number|workaround=comments}}
``` <sup>[Bug](#bugs):[1](https://dwarffortressbugtracker.com/view.php?id=1) (Workaround in comments)</sup> #### Linking to an article's "bugs" section Some articles have a separate section for bugs. Using this template without a bug number will link to that section. For example, ```
{{bug}}
``` produces this: <sup>[Bug](#bugs)</sup> If the section title containing bugs is something other than "Bugs", specify this in the `section` parameter. ```
{{bug|section=Usage}}
``` produces this: <sup>[Bug](#bugs)</sup> (this should jump to the Usage section of this documentation, which does not actually contain bugs). ### Bugs This is a sample section, which would contain bugs in a real article. It is here to serve as an example for linking to the bugs section.
