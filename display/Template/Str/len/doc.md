# Template:Str/len/doc

*[Source](https://dwarffortresswiki.org/index.php/Template:Str/len/doc) &middot; revision 190537 &middot; retrieved 2026-09-13 &middot; [wikitext](../../../../mirror/wikitext/Template/Str/len/doc.wiki)*

---
Calculates length of {{{1}}}.

### Examples

```
{{str/len|abc}}
```

→ 3

```
{{str/len|Dwarf Fortress}}
```

→ 14

```
{{str/len|a
b}}
```

→ 3

### Caveats

```
{{str/len|<nowiki/>}}
```

→ 34

This is due to MediaWiki's implementation of \<nowiki\> — \<nowiki\> tags are replaced with an identifier when parsed. For example, `<nowiki>text</nowiki>` becomes ``'"`UNIQ--nowiki-00000006-QINU`"'``. (Note that [purging this page](https://dwarffortresswiki.org/index.php?title=Template:Str/len/doc&action=purge) will display a different token, despite the contents being the same.)
