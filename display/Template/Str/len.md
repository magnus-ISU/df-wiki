### ([view](len/doc.md) - [edit](https://dwarffortresswiki.org/index.php?title=Template:Str/len/doc&action=edit) - [history](https://dwarffortresswiki.org/index.php?title=Template:Str/len/doc&action=history) - [purge](https://dwarffortresswiki.org/index.php?title=Template:Str/len&action=purge)) Documentation

Calculates length of {{{1}}}.

### Examples

```
{{str/len|abc}}
```

→ 3

```
{{str/len|Dwarf Fortress}}
```

→ 14

```
{{str/len|a
b}}
```

→ 3

### Caveats

```
{{str/len|<nowiki/>}}
```

→ 34

This is due to MediaWiki's implementation of \<nowiki\> — \<nowiki\> tags are replaced with an identifier when parsed. For example, `<nowiki>text</nowiki>` becomes ``'"`UNIQ--nowiki-00000006-QINU`"'``. (Note that [purging this page](https://dwarffortresswiki.org/index.php?title=Template:Str/len&action=purge) will display a different token, despite the contents being the same.)
