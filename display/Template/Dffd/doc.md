The dffd template is a useful macro for hyperlinks to the [Dwarf Fortress File Depot](../../Main/Utilities.md#dwarf-fortress-file-depot) (**DFFD** in shorthand). It can have two inputs: the file number, required, and a link name, optional.

`{{dffd|997}}` → [DFFD File # 997](http://dffd.bay12games.com/file.php?id=997)<br> `{{dffd|997|Dwarf Fortress Map Compressor}}` → [Dwarf Fortress Map Compressor](http://dffd.bay12games.com/file.php?id=997)
